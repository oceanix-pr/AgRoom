# 阿吉屋 · AgRoom

阿吉屋是一款原生 macOS AI 工作台。你可以选用自己的模型服务，让助手在指定文件夹内阅读资料、检索知识，或在授权后处理文件、邮件和脚本。生活与工作空间各有自己的对话、技能和数据库。

## 从源码运行

应用支持 macOS 15 及以上。构建需要完整 Xcode、macOS 26 或更新的 SDK，以及 Swift 6.2 或更新的工具链。已验证的环境为 Apple Silicon、Xcode 27.2 和 Swift 6.4.2。首次构建会从公开的 Swift Package 仓库和 GitHub Releases 下载锁定的依赖。仓库已包含 Xcode 工程和两种 CPU 架构的知识推理程序。

1. 在 Xcode 的账户设置中添加自己的 Apple 账户，准备该团队的 **Apple Development** 签名身份。
2. 在 `AgRoom/Config/` 下新建 `Signing.local.xcconfig`，写入下面这一行，把 `YOUR_TEAM_ID` 替换为自己的团队 ID。Xcode 会将同一团队用于主程序和两个空间的脚本执行器。这个文件只保存在本机。

   ```xcconfig
   DEVELOPMENT_TEAM = YOUR_TEAM_ID
   ```

3. 打开 `AgRoom/AgRoom.xcodeproj`，选择 **AgRoom** scheme 和 **My Mac**，按 **⌘R** 运行。

只运行核心测试时，从仓库根目录执行下面的命令即可。常规测试使用合成样例，真实模型、外部邮箱和已签名执行器的联调另行启用。

```sh
cd AgRoom
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swift test --build-system native --force-resolved-versions --no-parallel
```

## 第一次使用

1. 在「设置 → 模型服务」添加并启用一个提供者，填写它的端点、模型名称和所需 API Key。远程端点使用 HTTPS，本机回环服务也可使用 HTTP。
2. 准备一个测试文件夹，在里面建一个 `plan.txt`，写下「周二整理资料，周五提交报告」。选择「生活空间」，通过「添加已有工作区」选中这个文件夹。
3. 在该工作区新建对话，把权限设为「仅可查看」，输入「请读 plan.txt，列出两件事和各自的时间」。你可以对照原文件检查回答。使用远程模型时，这次读取的文本会随对话上下文发往所选提供者。

## 数据和权限

生活与工作空间分别使用 SQLite 文件保存会话、记忆、知识和邮件等资料。提供者配置在两个空间共享，API Key 保存在 macOS 钥匙串。模型请求会携带完成任务所需的对话、选中资料和工具结果。邮件同步、联网工具和模型下载也会按各自功能访问外部服务。

自动记忆提炼默认开启，可在设置中关闭。会话允许使用远程模型时，后台提炼会把符合条件的对话片段发给模型服务商。本机检索命中时，还会附带至多三条与这些发言相关的已启用记忆摘录。手动新增记忆默认在本机保存，选择「用模型分类」时会显示接收笔记的服务商。已启用的定时任务也可能调用模型。空间备份是可直接解压的 ZIP，其中包含会话、记忆和附件，请保存在私人目录。

对话的文件范围是当前工作区和你显式引用的文件夹。Shell 和 Python 脚本通过对应空间的离线沙箱执行器运行。项目构建工具会在宿主 Mac 上运行项目自己的构建脚本，每次都要单独确认。升级自旧版本的用户还可能保有待迁移的后台任务记录。

更多说明见[项目架构](docs/wiki/01-项目与架构.md)、[权限模式](docs/wiki/12-权限模式.md)和[构建与测试](docs/wiki/08-构建运行与测试.md)。发现越权、跨空间读写或凭据泄露时，请使用[私下报告渠道](SECURITY.md)。
