# 笔记与 Memonta 迁移

「笔记」位于主侧栏常用分组、导航菜单与独立应用菜单。入口复用 `HubNavItem`、`AppNavigation` 和 focused scene actions；内容、声纹、偏好与恢复目录始终绑定所属空间。

## 功能与宿主复用

| 功能 | 阿吉屋实现 |
| --- | --- |
| 笔记与资料 | 正文、标签、置顶、归档、全文搜索、分页、附件导入、原件导出、Markdown 与系统打印/PDF；全文搜索包括转写、总结和待办详情 |
| 截图与 OCR | 复用 `OCRService`；支持主屏截图、系统交互选区/窗口、全局快捷键 ⌃⌥⌘S、固定 OCR 文字窗口；标注支持移动、裁剪、画笔、矩形、椭圆、箭头、文字、马赛克、撤销重做、复制与贴图，保存副本并保留原图 |
| 录音与录像 | 麦克风复用 `TranscriptionService`；ScreenCaptureKit 采集系统声音、混合录音，以及系统选择器指定的屏幕或窗口录像 |
| 长音视频转写 | AVFoundation 分段切片，系统 Speech、现有云端 Provider 或本地 WhisperKit 三选一；系统支持时使用 SpeechAnalyzer，保留片段起止时间；逐段播放与编辑、搜索替换、说话人改名、波形、繁简归一、Markdown/拼音纠词和 SRT 导出 |
| 本地模型 | 用户选择 WhisperKit 文件夹或主动选择模型规格与下载源；说话人模型支持断点续传并校验公开权重；分析提供五档精度、CPU 线程设置、跨窗口身份细化、时长加权声纹和一对一姓名匹配，声纹库支持登记、试听、去重、合并与旧库导入 |
| 总结和待办 | 复用当前 Provider、端点策略、Keychain 与用量账本；自动判断会议/概要或自定义提示，长文分段汇总、流式预览与标题整理；待办以结构化 JSON 提取负责人、证据、来源时间、优先级、截止时间和提前提醒，并注入当前日期与时区 |
| 系统提醒事项 | 独立确认后通过既有 `RemindersService` 写入；复制数据不继承系统提醒事项 ID，不自动重放外部写入 |
| 录音恢复 | 每分钟轮转，原片归档、时间轴混音、可选离线参考回声消除、PCM 容器修复副本、健康报告、有限设备恢复；失败保留原片与已归档附件 |
| 视频画面分析 | 移植 Memonta 的关键帧算法；帧缓存、分批检查点、点击时间跳转、纯文字 OCR 路径与模型不支持图片时回退；画面结果参与后续总结与待办，明确不代表未采样内容 |
| 处理队列 | 复用 `JobCenter` 的进度、取消和回执；先预览将执行和跳过的转写/画面/总结/待办/标题阶段，逐阶段提交；离开页面继续执行，显式允许的退出任务可交接 Daemon，失败保留检查点 |
| 语音 | 独立面板选择正文/转写/总结、声音、速度与 WAV/M4A，先试听或导出；分块合成、取消和超时均清理临时文件 |
| 数据携带 | 文件流式 `.zwnote` 与口令加密 `.memontabackup`、逐条旧库预览/跳过/整批导入、来源幂等与中断继续；保留创建时间、独立标题、片段结束时间、总结历史、待办和当前关键帧；另复用宿主完整空间备份 |
| 资料管理 | 拖入文件、剪贴板建笔记、菜单录音入口；预览后合并录音并偏移时间戳、预览后清理媒体原件并保留文字与已分析的视频关键帧 |
| 文件镜像 | 用户选定当前空间专用文件夹，显式写入不可变修订并从导入预览恢复，不同空间不能共用同一镜像目录 |
| 文字隐私 | 本地实体、邮箱、电话、身份证与自定义词脱敏；词典可标记隐私姓名并从声纹库同步，另支持用户主动调用回环本地模型扫描；随机占位符随单次请求保留并还原，不涵盖音频、图片或转写上传 |
| 只读 MCP | 用户主动启动的回环 HTTP 服务，Keychain 令牌鉴权、Host/Origin 检查、有界请求，只提供当前空间的列表、搜索和正文读取；切换空间立即撤销 |

原应用的单例、全局数据根目录、独立 Provider 设置和更新器不复制。按产品要求不接入 CloudKit，也不实现云端自动双向合并。生活、工作空间中的笔记内容与附件、声纹、队列、偏好和录音材料保持物理隔离；文件镜像只提供当前空间的显式写出和预览恢复。

## 设置归类与生效规则

中央设置的「笔记与录制」位于「对话与助手」之后，各分类在同一纵向滚动页面内依次展示：转写、录音与录屏、AI 处理与提示词、转写词典、本地模型、说话人与声纹、语音朗读与导出、待办与提醒。上下文快捷入口打开同一页面并定位到对应分区。笔记页的设置按钮复用同一设置组件，并与中央设置使用当前空间同一个 `NotesModel`；不另建全局服务或第二套配置。

| 原设置 | 阿吉屋入口 |
| --- | --- |
| 语音转写、词典、本地模型 | 笔记与录制内对应子页；多份词典可命名、编辑、删除、启停和导入导出，兼容纠词规则、Markdown 表格、拼音词条及隐私姓名标记 |
| 大模型 | 模型服务维护凭据与端点；笔记与录制分别选择 AI 处理和云端转写使用的已有服务，缺失或停用不静默改用其他服务 |
| 提示词 | AI 处理与提示词；会议、概要、自定义总结及待办提取，支持恢复默认 |
| 录音、捕获 | 录音与录屏；默认来源、麦克风设备、开始静音、设备系统静音跟随、离线消回声、录像画质及声源 |
| 热键 | 通用 → 全局快捷键；统一管理主窗口与笔记选区截图，应用时反馈系统占用及重复组合 |
| 待办 | 待办与提醒；主动授权、默认系统提醒列表及刷新；单次写入仍需确认 |
| 声纹库 | 说话人与声纹；创建和匹配需要当前空间单独同意，撤销同意停止自动匹配，保留显式删除入口 |
| 数据管理 | 数据与备份 → 笔记数据；兼容导入、口令归档、镜像、内容占用与录音恢复 |
| MCP 集成 | 工具与自动化 → 本机笔记共享；与连接外部 MCP 的入口区分，保持只读回环及切空间撤销 |
| 关于 | 复用通用中的宿主关于、帮助与许可证；不接入旧应用更新源或专业模式开关 |

`notes.processing` 在空间数据库保存提示词、词典启停、声纹同意和服务选择；`notes.transcription` 继续保存识别与隐私配置。`notes.local` 保存设备和目录偏好，不进入便携备份；设备断开或默认提醒列表失效时要求重选，不静默向其他目标写入。应用级快捷键不携带空间内容。

单次总结、单条与批量队列共用提示词组装规则。队列在入队时保存总结和待办提示词及所选提供商身份；继续任务不读取新提示词覆盖快照。旧队列缺待办提示词时使用内置默认。输出结构约束及来源作为数据的边界保持有效。修改设置不触发生成、导出、下载、模型联网或提醒事项写入。

录制开始时固定设备、声源与质量配置；录制中可显式静音或解除静音。系统静音跟随只识别设备公开的系统静音属性，并在录制巡检时更新，不推断会议软件内部的静音状态。录屏配置更新失败进入现有录制失败/恢复路径。备份恢复保留声纹资料和提示词，但撤销声纹同意、停用自动声纹分析；必须在目标设备重新同意。

队列中的声纹设置不构成永久同意。UI 撤销同意会取消相关分析；App 与 Daemon 在执行前及写入分析结果前重新读取所属空间的当前同意状态，旧任务不能用已冻结设置绕过撤销。

单条导出、当次声纹登记、批量执行等内容操作保留在笔记页面；镜像等长期配置集中到中央设置。CloudKit 自动双向同步继续遵守既有排除边界。

## 笔记阅读布局

存储层以置顶状态、更新时间和 ID 给出下一页游标。加密搜索从已扫描的位置续读。同一查询的并发翻页共享一次读取。改变搜索、归档条件或记录排序时作废旧请求。编辑模型共用一个草稿保存任务，未编辑的已保存草稿可以直接切换。写入期间的新输入保留，版本冲突时本地文字留在编辑器。

笔记列表按创建月份倒序分组，可折叠；组内置顶优先，再按创建时间倒序。列表顶部提供页内搜索、新建、选区截图、导入，以及归档、批量选择和工具菜单。分页时月份计数仅代表已加载的记录。笔记行右键提供打开、置顶/取消置顶、归档/取消归档、导出与删除；操作绑定所点击笔记，删除独立确认，其他笔记的未保存草稿保留。分栏复用可拖动布局，宽度仅在拖动结束后保存。

详情顶部集中标题、保存、录制、总结、待办提取和处理流水线；正文、转写与附件在原始内容区切换，总结和待办沿阅读方向常驻下方。正文展示当前笔记的图片缩略预览；总结默认显示最新版本，编辑与历史版本在折叠区。待办卡片展示完成状态、备注、截止时间和提醒事项写入状态，详细编辑与系统写入仍沿原有编辑器和独立确认入口。

列标题、月份与分区标题使用共享 15pt 字体，搜索和笔记列表标题使用 14pt，状态、日期等辅助信息使用 12pt，详情标题与空态标题使用 20pt；这些界面字体均响应「标准 / 较大」偏好。正文、转写、总结编辑和待办内容遵循顶部「大小」入口的全局阅读字号，空态说明同样跟随阅读字号调整。

## 空间、并发与恢复

普通笔记作业与工作流在提交时取得绑定空间和作业 ID 的完成回执。作业从工具栏最近历史移除后，编辑器仍能收尾。执行结束但历史写入失败时，可以在任务中心单独重存回执。退出会等待普通作业及工作流收尾，超过期限时保留编辑器和草稿。

`Hub.makeNoteStore(for:)` 从指定空间的当前连接现取现建，不缓存服务。UI 模型固定空间；离开笔记页面不取消处理或录制，活动任务和未保存草稿由 UI 生命周期所有者保留。切换空间取消处理、停止并归档采集、关闭播放/朗读/贴图/OCR 窗口并同步撤销 MCP 访问。迟到任务不会改用新空间服务。

`notes` 保存快照，`note_media` 保存身份与文件元数据；大文件按有界块写入 `note_media_chunks`，完整校验后才发布。上传使用所有者和过期租约，崩溃后的稳定身份可以重试；未发布文件与暂存导入不进入列表或便携备份。删除使用外键级联。更新同时校验修订号和内容版本；备份恢复更换内容版本，旧编辑器和流水线不能覆盖恢复内容。异步模型结果写回前还校验原始草稿。卸载中的编辑绑定容忍空草稿，并按笔记身份拒绝迟到写入；保存后按身份重新查询，不回退到旧列表快照。

生产空间的笔记、队列、转写/画面检查点、声纹、说话人分析与录音报告正文使用 AES-GCM 加密；密钥按空间存入 Keychain，认证数据同时绑定空间与表名。空间开放前，后台按主键分批逐条认证密文，在同一事务中转换旧明文、清除标题与搜索投影并写入清理标记。整理 WAL 和空闲页成功后清除标记，挂载中断时可继续清理；加密空间搜索按游标逐条解密。密钥缺失或认证失败时关闭该空间的访问，不替换旧密钥。附件原件与 JPEG 缓存不属于正文加密范围。便携备份输出可迁移内容，恢复时用目标空间密钥重新加密，不携带设备密钥。

`note_transcription_checkpoints` 保存附件摘要及识别设置对应的分段前缀；隐私或说话人设置变化不作废已完成的语音识别。`note_visual_frames` 绑定媒体摘要与采样算法，画面检查点再绑定服务和分析模式。`note_workflows` 固定步骤、提示词、服务身份和后台许可；领取时生成新代次并持有需续租的跨进程租约，阶段结果与进度同事务提交。取消和普通重启后由用户继续；退出时先等待取消落盘、归档录制与保存草稿，再仅为用户已允许的任务发布所属空间的交接标记。检查点和执行权限不进入便携备份。

`note_voiceprints` 与 `note_capture_reports` 进入空间备份。模型文件夹、镜像目录的安全书签和设备偏好不携带到另一设备；恢复后本地模型需要重选，MCP 需要重新显式启动。

恢复原片位于 `<appSupport>/AgRoom/<space>/note-capture/<session-uuid>/`。固定 UUID 文件名和目录检查拒绝链接、路径穿越和特殊文件。稳定媒体 ID 使部分提交后的重试幂等；原片、混音及报告全部归档成功才清理目录。PCM 修复和回声消除始终生成新文件。明确记录为设备中断且无采样的分片保留无采样证据；有字节但不可播放的中断原片仍归档并在报告标记，其他分片可继续恢复。未知损坏或缺失文件不静默忽略。丢弃恢复材料需要独立确认。

录音巡检磁盘、采样超时、引擎状态与写入错误；麦克风/系统音频设备故障有限次数新建采集实例重试，超限停止保留材料。屏幕录像每分钟封装为 mp4；进程崩溃时当前尚未封装的片段可能不可播放，之前的已封装片段仍可恢复。

## 文件、模型与网络边界

文件接口单附件上限 64 GiB，笔记 JSON 上限 4 MiB；原有内存 Data 接口继续限制为 128 MiB。文件读写分块、校验已打开的文件身份和 SHA-256，拒绝链接及来源中途变化；旧库按目录清单逐条预览，不把整库媒体载入内存。原生单条包限制文件数量，口令归档另校验解密总量及可用磁盘。宿主完整空间备份继续遵守其总体容量限制，不能据单附件上限推断整库备份容量。录制/转写与合并录音最长八小时。视频有扫描点、帧数和 JPEG 总字节保护，多模态请求分批发送。语音导出、音频合成和原生分离窗口均有资源上限；原生分离的取消在当前有界窗口结束后生效。

普通目录包和镜像不加密，界面明确说明；镜像保留历史修订与已删除笔记的副本，不传播删除。空间标记禁止同一目录用于个人/工作空间之间的读写捷径。导入创建新身份，不覆盖同名笔记。

录音合并和原件清理均先冻结并展示计划，提交时重新核对内容版本与媒体身份。合并按创建时间连接音频，偏移片段起止时间和待办来源时间，成功后才删除旧笔记；当前保留的原音频另行改名。视频清理要求已有画面文字和关键帧，清理只移除原件字节，保留媒体身份、文字与关键帧。当前关键帧可随单条原生包、口令包与镜像恢复；不把采样结果描述成完整原视频。

口令归档兼容 Memonta 的 PBKDF2-HMAC-SHA256 和 AES-GCM 分块格式，逐块绑定原路径和索引；口令不保存。临时解密目录使用私有权限，逐项认证并预览后才写入当前数据库，取消/失败清理临时目录。单条原加密资料仅在用户主动选择后只读原 Memonta Keychain 密钥，不创建或修改旧密钥。

WhisperKit 与 sherpa-onnx/ONNX 的依赖固定在两个构建清单；许可证随 App 的 `Notices` 资源分发。模型主动下载需要网络，Whisper tokenizer 资源也需要预先下载以便离线加载。选择已有模型不读取原应用的录音、转写或密钥。说话人模型下载先校验公开权重摘要再发布目录。

MCP 默认关闭，令牌只在 Keychain。复制配置会将令牌放入剪贴板，UI 明示；服务只监听 `127.0.0.1`，不提供写入、任意 SQL、附件路径或空间参数。空间切换先撤销鉴权，再异步关闭监听器。

## 验证与交互验收

笔记相关测试覆盖空间隔离、密文认证与备份换钥、版本冲突、备份与授权剥离、大文件分块与中断导入、旧标题/创建时间/片段结束时间、长转写继续、长文末尾决策、云端接口复用、密码归档认证/篡改、旧待办/总结历史、镜像幂等与空间拒绝、既有回环 MCP 鉴权与撤销、脱敏还原、词典、关键帧纯算法及清理后携带、录音合并时间偏移与过期计划拒绝，以及合成音频混音/回声消除和原片不变。

`NotesPresentationTests` 使用隔离数据库和恢复目录挂载三语页面、本地模型设置和口令弹窗。`AGROOM_NOTES_SNAPSHOT_DIR` 指向已有目录可导出图像，不申请截图权限。

## 采集与纠词资源约束

麦克风 tap 仅持有单次音频文件和独立加锁的采样状态，不持有录音器或音频引擎。录音器释放时移除 tap 并停止引擎；显式停止仍返回原录音路径。持续写入失败每次录音仅记首次错误，健康检查继续报告失败，避免音频回调反复刷日志。

显式纠词按原文匹配范围一次拼接，替换结果不再次参与规则匹配，保留最长词优先、Unicode、同音词处理及取消检查。
