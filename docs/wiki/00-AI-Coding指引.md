## 项目定位

阿吉屋（AgRoom）是面向个人使用的原生 macOS AI 工作台，使用 SwiftUI、AppKit 和 Swift 6。数据以本地存储为主，LLM 推理请求按用户配置发往远端。产品围绕调度 Agent、工具调用、技能、知识、文件和生活/工作空间展开。

## 编码红线

### 空间隔离

- `personal` 与 `work` 使用独立数据库和独立技能目录。
- 空间内服务绑定单一 `DatabaseQueue`，不存在跨空间查询或写入 API。
- `Hub` 不缓存空间内服务；切换空间后 UI 重建相关页面和依赖。
- 新增数据类型时，必须先明确它属于全局还是某一空间。隐私内容默认属于空间。

### 模块边界

- 依赖方向是 App/UI → Core；Core 不引用 UI。
- 平台 UI 能力通过协议或 `extraTools` 注入 Core 运行时。
- 组合与对象创建集中在 `Hub`、`EngineAssembly` 或明确的界面组合点，避免在业务代码中散落第二套装配逻辑。

### 安全与副作用

- 密钥存 Keychain，不进入 SQLite、UserDefaults、日志或导出包。
- 非本机 LLM 端点使用 HTTPS。
- 对话文件访问只允许当前工作区的主目录与显式引用文件夹；同空间的其他登记目录不会自动开放，扩展访问模式也不能越过此边界。路径须校验穿越与目录身份。登记或引用目录需用户用系统选择器显式授权，且拒绝 `/`、主目录本身与 `~/Library`、`/System`、`/Library` 这类过宽或含系统/应用私有数据的位置。
- 删除、覆盖、自由代码执行、写数据库及用户可见外部操作遵循工具确认分级。
- 外部内容进入模型前保持数据边界和提示注入防护。

### 并发与可靠性

- UI 状态归 `@MainActor`；跨 actor 数据满足 `Sendable` 要求。
- 锁只保护短小的同步状态，不在锁内做 I/O、回调或 await。
- 长任务提供取消检查点、超时和确定的收尾路径。
- 持久化使用事务或原子替换；失败时保留可恢复状态，不能静默吞错。
- 重试要有次数上限和退避；有外部副作用的步骤不能盲目重放。

### 用户体验

- 用户文案统一通过 `L.string` 和三套本地化资源提供；模型提示词不做 UI 本地化。
- 用户可见错误包含原因和下一步动作，不直接展示不可理解的底层错误。
- 后台任务、确认、取消和失败状态应可见，完成结果必须可靠落盘。

## 完成标准

- 改动解决用户描述的完整行为，不留下半接线入口。
- 错误、取消、重启恢复和空间切换等相关边界已考虑。
- 运行与改动相称的测试；新增回归只覆盖有失败价值的行为。
- 新增或移动源文件后重新运行 `xcodegen generate`，并检查生成工程。
- 相关 Wiki 与最终实现一致，不记录容易失效的行号、文件行数、测试总数和版本快照。
