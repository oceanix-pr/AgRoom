# 稳定性、性能与资源生命周期审查

本次在当前工作区继续检查已有实现，保留既有未提交改动。旧审查结论只作为线索，修复依据为当前源码。覆盖 Provider/SSE、后台作业广播、语音采集、转写纠词、网页提取，以及浏览器标签、文档缓存、子进程和备份验证的资源边界。

## 本次修复

| 问题 | 影响 | 修复与验证方式 |
| --- | --- | --- |
| 麦克风 tap 闭包持有录音器，录音器又持有 engine/tap | 未显式停止时可形成循环持有，继续占用设备 | tap 仅持有文件及独立加锁采样状态；录音器释放时停止设备，避免最后一次释放发生在实时回调内 |
| 音频写入持续失败时每个回调均写日志 | 故障期间放大日志与 I/O 开销 | 每次录音仅记录首次写入失败，健康检查保留失败态 |
| 旧式生成流在响应拒绝或协议终止后未统一取消实际网络任务 | 服务器保持连接时请求可能存活至资源超时 | 交接前失败、生产任务退出及消费取消均关闭实际请求；协议桩保持连接不结束，检查客户端主动停止 |
| 消费流终止时直接释放 Provider 并发票据 | 上游尚未退出就可启动下一请求 | 票据由生产任务退出时释放，保留取消对底层请求的直接传递 |
| Provider 自建 URLSession 缺少显式销毁 | 重建 Provider 后会话资源收尾不确定 | 释放自建 session；注入的 session 继续归调用者管理 |
| 临时 JobCenter 销毁未结束广播 | 空间过滤转发任务可一直等待没有生产者的流 | 析构时结束订阅；回归核对 center 可释放且消费任务自行结束 |
| SSE 长行只在换行时检查取消 | 已缓冲但无换行的数据仍继续解析 | 开始读取及固定字节间隔检查取消，保留事件/响应上限 |
| 显式纠词每次匹配复制整篇正文 | 密集纠词随正文与匹配数量放大耗时和临时分配 | 原文范围一次拼接；回归核对 Unicode 和非级联语义 |
| 网页标签、属性和实体重复编译相同正则 | 大量节点解析有额外固定开销 | 复用不可变正则，无实体标记文本直接返回；复用原有文档提取回归 |

## 合成纠词性能

使用完整 Xcode Swift 工具链、Swift 6、`-O` 独立编译相同纠词代码；比较修改前的逐匹配替换与修改后的单次拼接。输入每行为 `😀 bad good é`，规则为 `bad=good`、`good=best`；每个规模各运行三次取中位数，每次比较完整输出相等。

| 输入行数 | 修改前 | 修改后 |
| --- | --- | --- |
| 1,000 | 184.0 ms | 2.93 ms |
| 5,000 | 4,472.9 ms | 14.65 ms |
| 10,000 | 15,751.7 ms | 27.69 ms |

此结果仅证明指定合成输入的纠词性能，不代表真实会议全流程、峰值 RSS 或 p95，也不作为 CI 墙钟门槛。

## 验证与边界

使用原生 SwiftPM 引擎执行测试，避免静态 ONNX framework 的默认引擎嵌入问题；同时构建并签名 Debug App。定向回归使用本地协议桩及隔离作业中心，不访问真实模型或用户麦克风。

已通过资源生命周期定向回归、修复后的全量串行回归与签名 App 构建。依赖截图开关的部分原生宿主用例按配置跳过，不计作真实窗口验收。验证入口（在 `AgRoom/` 下）：

浏览器已加载页面可能保留未保存表单，现有策略仅自动回收空白标签；不通过强制销毁页面换取内存下降。文档缓存已有数量与正文边界；备份列和主键在构造字典前已校验；子进程已有取消及超时收尾，本次保留这些边界。生活/工作空间物理隔离和工具确认策略未扩展权限。

真实设备录音、长时多标签 WebContent 进程、真实模型长流的 Instruments Allocations/Leaks、峰值 RSS 和主线程采样仍需专门运行环境与可重复数据。源码引用关系、协议桩与测试通过不能证明所有运行场景均无内存泄漏；本记录不作该保证。
