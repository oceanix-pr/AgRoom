# 智体模型、对话媒体与菜单审查

## 定位与范围

智体仍是主调度器可委派的专长执行者，既可单次委派，也可作为团队 Worker。独立模型选择补齐执行配置；统一对话入口、工具权限、审批与父任务预算的定位不变。

审查同时覆盖 macOS 应用菜单、状态项和主侧栏。当前已有业务功能较完整，本次菜单扩展集中解决可发现性、快捷操作、关闭主窗口后恢复，以及当前空间和焦点的正确性。各入口复用既有业务操作。

## 问题与实现

| 入口 | 原有问题 | 本轮落地 |
|---|---|---|
| 对话 | 智体只有模型名覆盖，仍复用主提供商；媒体附件仅图片可预览 | 智体独立提供商与模型；图片、视频、音频展示及原生播放；可缩放图片与可调整大小的图片、视频预览 |
| 文件 / 新对话 | 快捷键藏在聊天页，其他页面或关闭窗口后不便新建 | 文件菜单统一新对话，保护原草稿与附件，保留所选工作区 |
| 邮箱、应用 | 顶部只有独立应用入口，其余页面依赖侧栏 | 前往菜单与侧栏共用分组，提供直接导航；既有应用菜单保留 |
| 文件、知识、记忆、数据 | 入口分散，收起侧栏时较难到达 | 前往菜单覆盖全部资料页；统一搜索保留按来源打开、预览和引用能力 |
| 智体 | 专长职责、人设与模型选择关系不清楚 | 说明委派定位；继承或指定提供商；默认、候选和自定义模型；配置失效明确提示，不静默回退 |
| 技能、协作、定时 | 主要依赖侧栏进入，任务处理入口较深 | 前往菜单覆盖能力页；任务中心提供固定快捷键与状态项入口，既有审批继续生效 |
| 用量、设置、帮助 | 菜单与页面说明没有覆盖新增能力 | 用量纳入前往；设置及帮助同源路由保留；帮助补齐模型、媒体和快捷键说明 |
| 搜索与操作 | 只有工具栏快捷入口 | 前往菜单与状态项接入同一当前空间搜索 |
| 任务中心、成果库 | 入口藏在任务指示器等局部控件 | 前往菜单和状态项直接打开；保留本空间筛选、预览和来源路由 |
| 查找、导出、停止 | 会话操作集中在页内或上下文菜单 | 对话菜单按焦点提供查找、Markdown 导出和停止；缺少当前上下文时禁用 |
| 侧栏 | 通过隐藏按钮注册快捷键，菜单里不可见 | 显示菜单显式开关，移除重复快捷键注册 |
| 菜单生命周期 | 主窗口关闭后新操作可能无接收方，空间切换可能使迟到动作作用于其他空间 | 命令携带发起空间，挂起一次并补发，已消费不重复，空间不匹配即丢弃 |

## 数据与媒体边界

- 智体配置保存到所属空间库，旧数据迁移与 JSON 缺省兼容；完整备份保留提供商引用。普通委派和团队共用解析器，凭据仍只在 Keychain，用量仍归发起空间。
- 图片和媒体引用绑定会话的主目录与显式引用目录；远程音视频点击后才下载，验证地址及重定向，限制时间和体积，以私有临时副本供原生播放器读取。
- 页面退出、空间切换、关闭预览和加载取消均有收尾；界面播放不改变模型的多模态输入能力，不将视频或音频伪装成已理解的模型输入。
- 新导航不自动执行任务或批准工具，不新增跨空间服务缓存。

## 验证结果

按用户后续指示暂停全量回归。本轮定向测试已通过：覆盖旧库迁移、重开与空间隔离、备份恢复、普通委派与团队的实际协议请求及用量归属、Markdown 媒体语义、路径与下载边界、生成本地视频的原生播放与收尾、实际图片/视频预览视图的窗口伸缩，以及菜单挂起路由。测试使用临时资料和合成协议，不访问真实账号或外部模型。

三语资源检查、源码差异格式检查、SPM App 编译与 XcodeGen 生成均通过；完整 Debug App 的 Xcode 构建及签名通过。构建使用独立目录与有限并发，未运行全量测试，也未启动使用用户真实资料的 App。
