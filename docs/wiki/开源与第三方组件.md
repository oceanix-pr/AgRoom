## 源码发布范围

首次提交以根目录的 `.gitignore` 为准，纳入应用源码、测试、运行资源、两个依赖锁文件、共享 Xcode 工程、构建脚本和 Wiki。本地签名配置、个人笔记、独立内网采集工具及其文档、数据文件、缓存和导出包留在开发机。随源码提供的 `EmbeddingRuntime` 包含构建需要的可执行文件和动态库。

在新的 Git 工作树中，`git ls-files --others --exclude-standard` 可列出候选文件，暂存后用 `git diff --cached --name-status` 核对实际清单。沿用其他仓库的历史时，还应检查将要公开的提交、分支和标签。Git 忽略规则只影响未跟踪文件。
