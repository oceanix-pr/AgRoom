# 邮箱工作流

邮箱功能由空间内的账号服务、本地邮件服务、协议同步服务和 UI 编排组成。服务始终绑定发起空间；菜单、批量操作、导入导出均不能跨生活/工作空间获取数据。账号密码仍只在 Keychain。

对话工具 `mail_send` 在逐次硬确认时绑定实际发件账号、全部收件人和邮件内容，并在 SMTP 投递前重查账号。相同账号与邮件内容对应本空间同一份发送草稿；投递仍在进行或结果不明时，重复调用须先核对原投递状态。

## 列表、查询与操作

同步按文件夹分批预取已有 UID。有缺失时再批量查同文件夹的 Message-ID。批内每处理一封就更新映射，因移位而得到新 UID 的邮件保留本地身份、正文、附件和待回写标记。服务器将旧 UID 分给另一封邮件时，清理旧邮件及其内容。整批写入在同一事务内提交。

邮件列表支持原生多选。上下文菜单由系统传入实际目标集合，右键选中集合里的邮件作用于集合，右键其他行作用于该行；菜单构造不改变正文选择。多选时不加载单封正文。详情、列表菜单、选择菜单及邮箱应用菜单复用相同动作。

单独打开邮件或展开会话中的某封邮件时，立即在所属空间标为已读，更新未读圆点、文件夹和统一收件箱计数。未读筛选会保留正在阅读的邮件，离开后移出列表。远端邮件通过已有标记队列回写 IMAP，离线可继续阅读，下次同步补写。本地归档只更新本机状态。

查询在数据库过滤后再做日期、UID、本地 ID 游标分页，覆盖所选范围内全部本机缓存的主题、发件人、摘要及可读正文。可组合未读、星标、有附件、发件人、收件人、附件名、邮件大小和起止日期；截止日期包含当天，上限大小条件不把未知大小当成符合。范围可选文件夹、账号、统一收件箱或当前空间，跨账号结果显示实际账号和文件夹。输入防抖，查询及范围切换作废旧回调。这个搜索不代表远端邮件全集，也不搜索未缓存正文。

常用筛选保存名称、条件和范围，随当前空间备份恢复。应用时先验证来源；原账号或文件夹已删除时提示重新选择，不改查其他账号。跨账号结果的回复、移动、归档和废纸篓操作均按目标邮件实际归属处理；混合账号不能移动到某个单一账号的文件夹。“在原文件夹中显示”清除搜索条件、恢复文件夹范围并定位原邮件，不用置顶项充当分页游标。

保存筛选可重命名，或显式选择用当前条件和范围更新；默认编辑只改名称，不改变原条件和身份。提交在事务内核对打开编辑器时的原记录，已被修改或删除的记录要求重新打开，不覆盖新内容或复活已删除项。来源已失效的筛选仍可改名，但应用时继续报告来源不可用。

单封菜单只显示当前需要的已读/未读、星标/取消星标操作；混合选择保留两种方向并显示实际受影响数量，冻结相应邮件 ID。菜单可查看完整邮件头或原始邮件，先读当前空间保留的原件，缺失时由用户显式获取。原文使用只读原生文本视图分页显示，不执行 HTML 或自动打开链接；查找与复制只针对当前页，EML 导出仍保留原始字节，重建副本明确标记。

邮件右键与选择操作菜单按回复、标记、移动/归档/删除、导出分组；单封的 AI 回复、元信息复制、发件人筛选及完整邮件头/原文放在「更多」。跨文件夹、账号或搜索批次中的「在原文件夹中显示」仍在首层，已处于该文件夹时放入更多，避免重复入口。多选显示本次集合数量，标记按实际子集计数，移动、归档、恢复、删除和导出按冻结集合显示数量。不可用说明集中到独立子菜单，相同原因只列一次并保留对应动作；上一批仍在运行时仍能查看原因。菜单重排不改变右键目标、既有确认、批量回执或未知写入的处理方式。

普通删除移至同账号废纸篓，废纸篓内显示永久删除；两者均确认实际数量。废纸篓可移回收件箱或其他文件夹。永久删除执行前在账号租约内再次核对当前文件夹归属，确认期间已移出的邮件拒绝删除。缺失目标文件夹时提示先同步或使用明确的移动目标，不能回退成永久删除。归档按该账号已识别的归档文件夹执行。

批量操作冻结邮件 ID，逐封复用既有账号租约、远端写入与本地回执。结果分别呈现已处理、失败和未处理数量；取消保留已完成结果。标记操作以本地为权威，远端待回写继续使用既有队列；本地自产副本不向 IMAP 发送保留 UID。只有幂等标记提供直接重试入口，移动或删除失败需先同步并核实服务器结果，不自动重放结果未知的写入。

文件夹右键支持同步此文件夹、将该文件夹全部本机缓存邮件标为已读；后者不受列表页大小或当前筛选限制。回复全部保留 Reply-To 与线程链，按地址去重并排除当前账号地址；原邮件不推导密送收件人。

文件夹可收藏或取消收藏，侧栏在当前账号下单列收藏，原目录树和层级保留。移动选择器将同账号的最近成功目标及收藏置前，排除已处于目标文件夹的完整选择，混合账号不提供单账号目标。只有显式选择文件夹且取得成功回执的移动更新最近目标，失败、归档与移至废纸篓不更新；按账号保留有界历史，淘汰最近记录不删除收藏或隐藏偏好。批量操作保持忙碌直到列表归属刷新完成，避免菜单继续使用移动前的位置。偏好位于当前空间数据库，随备份恢复；删除文件夹或账号会级联清理。

文件夹右键可在侧栏隐藏或显示，容器也可隐藏。隐藏沿同账号的实际父子关系影响子目录与收藏区，不按名称前缀误伤相似目录，不改变同步、统一收件箱、搜索、移动和导出范围。侧栏提供显示隐藏文件夹的开关，隐藏项显示图标；子项可先显示隐藏的上级，子项自身的隐藏偏好仍保留。隐藏当前目录不切换正在阅读的邮件，主区显示说明与恢复侧栏查看入口。偏好随当前空间备份恢复，旧版偏好记录缺少隐藏字段时默认显示。

列表右键、选择菜单、单封/会话详情及邮箱应用菜单共用可搜索的移动选择器，按名称和完整路径匹配，保留同名目录的层级区别；远端路径展示时解码，本地归档路径原样显示。选择器包括侧栏隐藏项，固定打开时的邮件集合与实际账号；打开和提交均只读，点击移动后才启动既有批量操作。复核记录仅在内存保留并绑定发起数据库连接，相同 UUID 的恢复副本或替换后的连接也不能复用。提交前核对账号连接身份、每封来源、UID 与 Message-ID、源及目标目录路径和 UIDVALIDITY；逐封执行时在账号租约内再次复核。变更或删除后要求重新打开，不改用其他来源；标记变动不作身份失效。关闭、离开邮箱或切换空间取消选择器在途工作，取消后的窗口不能提交。列表、详情及应用菜单对移动、归档、恢复和删除显示不可用原因，包括跨账号选择、缺失语义目录、已在目标目录、账号停用和上一批仍在运行。

## 文件夹管理与结果核对

侧栏底部、账号菜单、文件夹右键及邮箱应用菜单共用当前账号的管理窗口，支持完整路径搜索、新建顶层或子文件夹、重命名、删除、收藏及隐藏。服务固定发起空间、账号和数据库连接；离开邮箱、关闭窗口或切换空间作废在途预览。容器可管理但不进入邮件读取，系统角色文件夹及含系统角色的子树不提供重命名或删除。

新建和改名先输入名称，再只读预览具体路径；删除入口只打开范围预览，不执行删除。确认页列出整棵目录树、本机邮件数和读取时的服务器数量，明确本地归档与服务器删除的区别。删除目录会永久删除其中邮件，不移入废纸篓；服务器上的整个目录属于确认范围，包括确认期间新收到的邮件。新增子目录、路径或账号身份变化要求重新预览。本地删除另核对完整邮件集合，预览后新增邮件时拒绝执行。

本地归档的新建、改名和整树删除在空间库事务内完成，不读取凭据或连接服务器。改名保留目录与邮件 ID、原件、正文、偏好和保存筛选；导入目录的内部命名空间及原始去重来源保持稳定。远端操作沿用账号和维护租约，重新核对 LIST、路径及 UIDVALIDITY 后调用 CREATE、RENAME 或 DELETE，目录名在协议边界只编码一次。整树删除逐个处理子目录后再处理父目录，不把 DELETE 当作递归命令；参见 [IMAP DELETE 与 RENAME 语义](https://www.rfc-editor.org/rfc/rfc9051.html#section-6.3.5)。同步恢复租约后核对原目录路径；邮件摘要写入、缓存清理、UID/标记对账、覆盖与同步游标事务再次核对来源路径和未决意图，拒绝独立连接在改名后返回的旧目录结果。

服务器写入前持久化意图，分别记录待提交、已提交、已确认、结果未知及终态；每个账号同时只保留一个未决操作。逐目录保存成功回执，取消保留已经完成的部分，失联不能当作服务器未执行。未决操作保护该账号的目录对账及依赖目录身份的网络操作，界面引导前往管理窗口核对，不自动重放。记录随当前空间备份恢复，恢复备份不会重新执行服务器命令。

核对入口只读取当前服务器状态；最终确认再次核对记录、目录和缓存集合。已知成功且邮件身份可证明的改名保留原缓存；响应丢失后的改名不能仅凭目录名与 UIDVALIDITY 认定旧 UID 仍可靠。需重建缓存时显示具体目录、缓存数量及待同步标记的清理范围，用户勾选了解后才能确认；本机自产原件保留，包括已被普通同步关联到服务器 UID 的副本。该同意只在当前窗口内有效，不随记录或备份保存。核对只收尾当前步骤，剩余删除目录需重新预览和确认；无法可靠关联时保留旧缓存并提示先在邮箱服务商处核对。

## 服务器草稿同步

本机自动保存仍不联网。撰写窗口的「服务器草稿」菜单先展示保存预览，确认后才上传；初次使用需先同步账号并识别唯一可选择的草稿目录。当前路径要求 UIDPLUS，以便取得 APPENDUID 并仅清除目标 UID，不使用全目录 EXPUNGE。草稿 MIME 包含本草稿的密送和附件，SMTP 的密送继续只进信封，不复用草稿 MIME 发送。

保存预览固定发起空间数据库、账号端点、目录及 UIDVALIDITY、本机草稿内容和既有服务器版本。确认前及账号租约内复核；旧服务器版本的 UID、Message-ID、Draft 标记和原件摘要必须匹配，已被其他客户端编辑或替换时停止并保留本机修改。原样再次保存只核对，不重复上传。新版本上传前在 `mail_server_drafts` 写入固定 Message-ID、内容摘要和快照；确认 APPENDUID 后再次读取原件核验，成功才记录新版本并清理旧版本。

上传失联、取消、缺失回执或重启保留未决凭证，不能直接再次上传。「核对服务器结果」只读搜索对应 Message-ID，必须唯一且原件摘要匹配才收尾；找不到或歧义时保留现场。用户手动核对服务器后，可明确清除未决上传凭证，界面说明已有副本可能仍在、再次上传可能产生重复，并保留 Message-ID 记录。旧版清理单独保存待处理状态；明确核验后可继续清理，或选择保留旧副本并结束清理，不自动重复 APPEND。

「预览服务器版本」读取当前关联版本；同一 Message-ID 的唯一服务器新 UID 可作为显式读取候选。未变化的版本保留本机正文与原文引用分区；服务器改写后重新解析主题、收件人、密送、正文和附件，引用文字可能合并进正文。用户明确替换当前本机草稿后，再次核对远端与本机快照，并在事务中一起更新本机草稿和关联凭证；不覆盖预览期间的新编辑。账号和发件身份固定，不从服务器内容切换发信账号。

确认 SMTP 投递成功并落本机投递凭证后，只清理同一草稿已关联且原件仍未变化的服务器副本，写前保留清理领取；投递未知时不清理。清理失败不报告发送失败、不允许重发：先保存本机已发送副本并保留已投递锁定草稿，提供只读核对和明确清理入口。服务器原件已变化时保留，需到服务商核对；已发送副本本身仍只落本机，不使用草稿 APPEND 自动回写服务器已发送目录。

服务器草稿凭证及快照归属当前空间并随完整备份保存。恢复后的凭证须先只读核对，不重放服务器写入；目标库已有的凭证不被导入版本覆盖。恢复凭证本身不能证明 SMTP 已投递，投递后清理仍要求本机独立投递凭证。账号密码不进快照；所有网络步骤沿用共享账号和维护租约、超时与取消。

## Finder 拖出与本机邮件引用

单封邮件的「更多」菜单可打开 EML 拖出准备窗口，先取得并复核当前空间的邮件来源与原件。缺失原件需用户明确选择获取，生成的重建副本沿用既有说明。原件就绪后，将拖拽区拖到 Finder，使用系统文件承诺按目标的确切名称保存；写入前再次核对冻结来源，只创建新文件，不覆盖旧文件。切换空间或关闭准备窗口使尚未提交的请求失效；已经完成的文件保留。此入口一次处理单封，大批量仍使用完整导出预览与结果清单。

邮件复制菜单提供不含主题、地址和正文的本机来源 URL，包含所属空间、账号、邮件本机身份及来源摘要。只读打开必须在当前空间解析，并核对账号和来源摘要；不会自动切到另一个空间，不访问其他空间库，不按主题或 Message-ID 搜索替代邮件。同一归属中的移动可保留引用，原邮件被删除或替换后提示重新复制。Markdown 链接和应用 URL 入口共用当前空间解析，来源导航继续使用原文件夹定位和分页，引用不能触发发送、写信或联网补全。引用为本机定位信息，不携带外部路径、访问授权或可跨设备保证的身份。

## 对话里引用邮件和保存回复

邮箱列表和搜索工具返回每条结果的本机邮件链接。回答可以只列部分结果，也可以重排。用户再说“刚才第二封”时，前台按当前会话、空间和工作区中所选回答版本显示的顺序解析，并在读取和撰写时复核原邮件。回答中有多组列表、未显示有效链接或记录已失效时，用户可以提供明确的邮件链接。分支和导入的历史不会继承原回答的选择凭据。

回复草稿按原邮件的 Reply-To 或发件人核对收件人，并记录原邮件的本地 ID 和邮件头。同一运行对同一原件、同一发送账号重复保存回复时，空间数据库只登记一次。在此期间用户已编辑的草稿保留修改，已经删除的草稿也不会重新出现。新会话轮次可以独立草拟回复。“先别发”会从该任务的工具面移除发信，并持续约束确认、子任务和后台恢复。保存草稿使用原有确认流程。用户明确要求保存邮件草稿时，必须收到本地草稿的保存回执，任务才记录保存成功。SMTP 超时和已投递但本地副本保存失败会显示不同的核对提示，两种情况下都暂停后续写操作。

## 签名与回复模板

写信窗口正文上方的「签名」菜单可插入现有签名，也可选「从邮箱导入签名」。选取当前账号的已发送或草稿文件夹，再打开其中一封近期邮件。标准分隔线后的签名会预先选中，也可手动框选文字。确认后可修改名称和内容，并决定是否作为该账号的默认签名。点「保存」后生效。

要取网页版当前使用的签名，可在网页版保存一封仅含签名的草稿，再从草稿文件夹导入。签名导入使用账号现有的 IMAP 连接，先列出近期邮件，再读取选中邮件的正文。HTML 签名会转换为可编辑的纯文字。网页版的签名设置由邮箱服务商管理。[IMAP 协议](https://www.rfc-editor.org/rfc/rfc9051.html#section-2.4)

签名和常用回复模板保存为当前空间的纯文本偏好，按类型管理名称和内容；签名可按在线发信账号设置默认值。新增、修改、删除和账号默认值通过整份快照比较提交，并发变化要求取消编辑并刷新，不覆盖另一窗口的新内容。编辑尚未保存时不能切换条目或关闭管理窗口，取消编辑可放弃本次变化。数量、名称长度、单项和总内容大小均有界，多语言文案不改写用户保存的文字。

默认签名仅在尚无本机保存记录、正文为空且用户未开始编辑的新草稿中应用一次，打开已有草稿不重复添加。手动插入先展示确切文字；回复模板可追加或明确替换正文，当前窗口管理且用户未改动的签名可明确替换。保留原文引用、收件人、主题和附件。插入后可撤销一次，但手动修改正文后不再覆盖用户的新内容；预览期间正文变化须重新预览。普通自动保存仍只写本机草稿，不因此发送邮件。

模板及账号默认设置随完整空间备份恢复；校验内容和签名引用，删除签名同时移除对应默认值。管理和撰写窗口固定发起空间，服务现取现建，不把空间服务缓存到 Hub。

## 写信与格式

顶部工具栏提供发送、保存本机草稿、添加附件或图片附件，以及收件人检查。收件人、抄送和密送可按地址逐项移除，编辑时可粘贴含姓名的地址列表。检查窗口按三种收件方式列出地址及格式结果。Command–S 保存本机草稿，Command–Return 发送。

正文可对所选文字或接下来输入的文字使用加粗、斜体和下划线，快捷键分别为 Command–B、Command–I 和 Command–U。带格式草稿在本机保存和恢复时保留这些样式。服务器草稿、实际投递及已发送副本都包含纯文本与 HTML 两份正文，附件在两份正文外单独封装。未设置样式时继续使用纯文本。

## 统一收件箱与会话阅读

统一收件箱是当前空间内所有本机收件箱角色文件夹的查询，不合并生活/工作数据库，也不把账号中的其他文件夹算作收件箱。离线归档及停用账号已有的收件箱邮件仍可阅读；刷新仅逐个同步已启用的在线账号收件箱，沿用文件夹发现与账号租约，不顺带拉取其余文件夹历史。单账号失败不终止其他账号，结果提示失败账号名称；取消断开当前读取并停止后续账号。未读徽标按本机实际邮件计数，界面说明当前范围和本地覆盖边界。统一收件箱可筛选、保存筛选和导出全部匹配项；点击保留的原账号或文件夹可回到文件夹范围。

会话阅读从当前邮件出发，仅在同账号、同空间内按 Message-ID、References 和 In-Reply-To 的精确标识建立传递关联；共享缺失父邮件的兄弟回复也可关联，不以主题相同或子串匹配合并。摘要可学习直接父邮件，正文和保留原件补全祖先链，后续部分摘要不截断已知链。迁移从旧元数据和保留原件建立派生索引；索引跟随邮件更新与删除，备份和回退通过原记录重建，不将派生表当作独立用户资料携带。

相关邮件按日期和本地 ID 升序分页，未注明日期的邮件先显示。当前选择不在首批时作为独立卡片保留，续页游标只来自正常页，避免跳过中间往来。这里只表示本机已知线程头覆盖，展开未缓存邮件才读取其正文，不自动补齐服务器整串历史。单封与会话模式由空间邮箱模型保留；会话模式不再同时启动单封正文读取。

每张展开卡片固定自己的空间与邮件身份，复用详情组件及原有确认策略。正文、附件和 CID 图片由卡片负责；折叠或离开时取消在途读取并释放呈现字节，重试继续核对原邮件。卡片菜单和详情按钮直接作用于该封，选中卡片的边框表示邮箱快捷操作的当前对象；返回列表或单封模式时恢复列表选择对象。每张卡片显示真实账号与文件夹，跨文件夹往来不借用侧栏当前账号决定回复或移动目标。

## 附件保存与标准格式导出

主窗口通过当前空间邮箱模型运行自动收件箱轮询，不依赖邮箱页面是否正被选中；自动同步及新邮件提醒默认关闭。启用后仅对已启用在线账号发现目录并同步收件箱，不拉取其他文件夹邮件或附件，不连接本地归档及停用账号。每轮现取现建空间服务，沿用账号租约和原有超时取消，多窗口按数据库连接限制一个监视者；切换空间取消本轮，退出应用后不继续联网。

自动同步的设置及收件箱 UID 基线位于所属空间的偏好表。首次启用、账号连接身份变化及 UIDVALIDITY 变化时先建基线，不提醒历史邮件；之后只统计超过基线的新增未读邮件，不把同步更新条数当作新邮件数。保存基线后再通知，提醒失败不反复播报同一批；单账号失败保留错误并继续其他账号，下一轮按正常间隔检查，不盲目快速重试。通知只含数量和空间名称，不含主题、地址或正文；系统授权仅在用户主动开启提醒时申请，后台检查不触发权限弹窗。完整备份恢复会关闭自动同步和提醒并清空基线，重新启用由用户明确决定。

列表显示可选择最新、最早、发件人或主题排序，以及隐藏或显示不同摘要行数、舒适或紧凑间距，设置保存在所属空间的 `product_preferences` 中。排序在过滤后的数据库请求中执行；日期空值位于末尾，UID 与本地 ID 用于稳定处理并列项，主题与发件人使用原始存储字段和同一 SQLite 排序规则生成游标，不以已解码的展示文字猜测续页边界。更改排序重新加载列表，来源定位的额外固定行不改变分页游标。

查询词在列表的可见主题、发件人和摘要中高亮；正文查找只作用于当前显示邮件，默认采用当前查询词，可独立编辑并选择上一处或下一处，正文无匹配时明确提示。查找调用 WebKit 原生接口，保持 JavaScript 禁用、原有 CSP 和远程内容限制，不向邮件正文注入脚本；换邮件、重载或关闭时使迟到查找回调失效。

批量标记、移动、归档和移入废纸篓在账号租约内取得操作前后身份；只在操作确认成功且状态发生变化时生成当前会话的撤销凭证。永久删除、失败和结果未知的项目不产生可回退凭证，远端邮件须能核对目录 UIDVALIDITY。标记成功沿用本机权威与待回写队列语义。结果栏可定位实际成功邮件，也可先预览撤销数量、跳过数量、恢复的标记及原目录，再明确确认。

撤销再次核对发起数据库连接、账号端点、邮件 ID/UID/Message-ID、所在目录及原目录身份；标记操作还核对对应当前值。变化或缺失项目跳过，不借用同名目录或另一空间。每项回退只可领取一次，传输错误或取消后的未知结果不自动重试；本机回退在同一事务内重验并修改对应字段，远端回退复用原账号租约及协议路径。凭证不序列化、不随备份恢复，也不在重启后重放；切空间取消在途界面请求及过期确认。

归档文件夹是一种独立的目录输出格式，即使只有一封也创建新的归档目录。每封拥有独立目录，保存原始 `message.eml`、只包含转义文本的可读 `index.html`、逐个编号的附件及 `manifest.json`；根目录保存可读索引和完整结果清单。HTML 邮件转为文本，正文不执行脚本、表单、远程图片或作者样式；附件来自同一完整原件并逐项记录长度与 SHA-256，不按文件名猜测或合并。重建原件保留明确说明。每封可读页最后发布，附件或其他文件失败时该封不计成功；根索引列出未完成项，取消保留已经保存的文件和清单，索引整体失败提供重新导出到新目录的入口。

文件夹菜单分别提供只导出本目录和包含全部子目录的动作。包含子目录时在同一数据库读取中按实际父目录关系遍历同账号树并固定本机邮件 ID，拒绝循环及过大目录集合，不按路径字符串前缀猜测层级；范围说明明确包含子目录且不代表远端全集。后续保存沿用冻结来源复核、完整度预检及用户选择的补全下载策略。

邮件列表右键、选择菜单、工具栏和邮箱应用菜单提供导出入口；文件夹右键导出该文件夹全部本地邮件，目标不受列表页大小限制。发件人/收件人右键只生成待发草稿或筛选，不直接发送。

工具栏区分所选邮件与全部搜索结果。搜索结果导出在数据库按实际条件一次获取所有本机匹配 ID，包含尚未加载的列表页；打开导出时固定集合。预览说明所选、文件夹全部本机邮件或搜索范围，不能将未同步的远端邮件算入完整导出。

EML/PDF 文件名可选主题、日期与主题、日期与发件人及主题；输出可平铺、按实际账号与邮件目录层级或按月份分组。目录名称和文件名在后台提前确定，规范等价、大小写和文件/目录重名在预览中分配独立名称，保留同名账号与目录的身份区别，并预留根结果清单。路径预览可检索完整集合并分页展开；单个平铺文件仍允许在系统保存窗口中改名。目录输出按预览名称独占新建，不接管已存在目录，也不在保存时静默换名；嵌套目录固定句柄并在写入前后核验，替换、链接或外部占用报失败。

预检只读取当前空间元数据，不下载、解析原件或读取口令。分别列出本机可准备、缺失及无法从服务器补全的数量；EML/MBOX 汇总已知完整报文大小并列出未知数量，PDF 不把完整报文大小当作正文下载量。预估不保证缓存之后不被淘汰或服务商仍有邮件。没有可联网来源时只显示本机内容说明；混合选择中，补全选项也不会让本地归档、停用账号或受未决目录操作保护的来源连接服务器。

内存预览绑定发起数据库连接、账号连接身份、邮件和目录身份及命名元数据，不保存凭据、外部位置或审批。点击保存时先固定格式、命名、分组和补全选项；系统选择器返回后，在创建输出目录前重新复核，逐封读取和发布前继续复核，网络路径在账号租约内核验冻结来源。来源已变更要求重新预览，不借用其他空间或新端点。关闭使在途预览和后续提交失效；取消运行保留成功文件和结果清单，重试只处理未保存项，重新复核并选择位置，目录输出使用新的默认名称。

保存附件复用按需下载与当前空间缓存校验；本地已缓存附件即使缺少旧版 MIME 部件身份也可直接保存。缓存读取拒绝目录链接、文件链接、硬链接和超限文件。批量保存创建独立输出目录，同名附件分别保留；结果清单文件名预留，不能被同名附件占用。

阅读器与会话卡片共用当前空间的附件准备队列。点击预览或打开也经队列准备，另可仅将单个或全部附件入队；相同来源中的在途附件合并等待者，串行执行，任务只保存原邮件及附件描述和内存来源预检，不缓存空间服务。暂停只阻止新任务开始，当前项可单独取消；任务列出排队、准备、就绪、失败或取消状态，协议尚未提供逐字节进度时不显示伪造百分比，完成后显示实际大小。

入队固定账号、邮件、目录和附件身份，开始读取时在原账号租约内复核，变化不自动采用替代邮件或部件。重试保留原来源预检；需要变更来源时由用户重新选择附件。完成后打开或定位再次复核原来源并检查文件摘要；切换当前邮件或折叠卡片使旧呈现请求失效，但队列可继续准备。切换空间取消待处理任务并作废迟到回调。队列和元数据预检均有数量上限，结束记录可清理，清理不删除业务附件缓存；队列不持久化，不在重启后自动下载。

附件行与右键使用一致的读取/下载及预览文案；未准备的在线来源提示可能需要下载，本地归档或自产副本说明从保留的邮件中离线读取。右键提供预览、默认应用打开、另存为及复制文件名；有本机文件记录时再提供 Finder 定位，实际读取仍核验缓存。准备期间禁用涉及文件读取的动作，复制非空文件名仍可用且不触发下载。导出窗口的 Escape 沿用取消/关闭动作：运行中先取消并保留结果，空闲时关闭，不绕过保存位置或补全下载选择。

EML 导出保留收到的原始完整报文字节，不从解析后的正文伪造原件。服务器读取使用有字节上限的 `BODY.PEEK[]`，核对已知 UIDVALIDITY 和 Message-ID；迟到缓存写入在数据库事务内再次核对本地邮件身份。旧本机发信副本没有原件时，仅对完整纯文本副本生成明确标记的重建文件。

MBOX 导出使用 mboxrd，按邮件正文行转义 From 前缀，不重组 MIME、不转换原件换行。批量按记录边界分卷，每卷受现有文件字节上限限制；单封无法原样放入 MBOX 时明确提示改用 EML。导出仍复用原件覆盖预检与可选补全下载。只有分卷原子保存成功，卷内邮件才记为成功；清单逐项保存文件名、来源种类、原件字节数和 SHA-256。取消时保留已落盘分卷，缓冲中与未开始的邮件记为未保存，清单仍收尾；重试只处理未保存项并重新预检与选择位置。

MBOX 可按账号目录或月份分组，各组独立编号；预览展示每组首卷，并明确后续卷数由写入时的实际报文大小决定。所有可能的卷名避开预览中的子目录，目录之间不合并同名身份；清单记录相对路径，结果保持原选择顺序。

`mail_raw_messages` 在当前空间库单独保存完整报文及来源；服务器原件缓存受单封及总字节上限限制，本机生成副本不按远端缓存淘汰。邮件身份失效、删除或删账号会清理其报文，完整备份包含报文，恢复时验证类型和大小。原始报文缓存与本地归档来源分开；归档保留的原件不参与远端缓存淘汰。

PDF 复用阅读器禁止外部资源的 HTML 文档及历史 HTML 识别规则，保留主题、发件人、收件人、抄送和日期。WebKit 先生成矢量 PDF，再按纸张尺寸分页，分页避开普通文本行；绘制在后台执行并检查取消、页数和输出大小。支持的 CID 图片从当前邮件附件读取并进入 PDF，独立附件不嵌入，远程图片仍阻止。未勾选补全下载时只读缓存及可从本地原件恢复的附件，不读凭据、不连接服务器；内嵌图片缺失或无法读取时报告该封导出失败，不把缺图文件记为成功。

PDF 正文缓存缺失时优先从当前邮件保留的原件离线恢复，收到的服务器原件也适用；附件按已知本机部件身份或唯一匹配的文件名、类型、Content-ID 和内嵌标记恢复，不凭相同文件名猜测重复部件。Content-ID 的尖括号呈现不影响匹配。原件恢复失败保留明确错误，不把摘要当作完整正文。

导出读取回写正文、线程头、摘要和附件元信息时，在同一事务内再次核对固定来源，任一步失败一并回滚；附件文件缓存的登记也在事务内复核来源和部件身份。原件恢复仅在新旧部件均唯一对应时保留旧附件 ID 和已下载路径，不将一个同名缓存分配给多个部件。

## CID 内嵌图片

CID 处理器位于 UI 层，固定当前邮件身份与发起空间，服务仍按该空间现取现建。URL 只用于匹配该邮件的 Content-ID，百分号编码只解一次；缺失或重复 ID 拒绝读取，不把标识当作文件路径或外部地址。附件通过既有账号租约、空间内缓存校验和本地原件恢复流程读取，远端读取沿用字节限额、超时及取消；读取后再次核对账号、文件夹、UID 与 Message-ID。

在线 BODYSTRUCTURE 解析和部件下载共用文件/资源判定，保留显式附件、带 Content-ID 或文件名的部件及内嵌图片，不要求 CID 图片声明 `attachment`。HTML 根部件自身带 Content-ID 时仍可作为正文读取。服务器缺少 BODYSTRUCTURE 时，完整报文的有界回退使用本地 MIME 解析规则，并在同一来源复核事务内保存原件、正文和本地部件编号；后续图片可离线恢复，原件被缓存淘汰后也可通过一次新的有界读取恢复。

旧缓存缺少对应 CID 元数据时，同一图片来源最多共用一次补查：优先离线重解析当前邮件保留的原件，允许下载时才连接原账号读取正文和部件结构。离线 PDF 不读取凭据、不联网。并发图片共享补查，最后一个等待者取消或离开页面时取消补查；缺失或重复的 CID 仍明确失败，不逐张无限重新下载。补查得到的附件同步呈现在阅读器中；「重试图片」重新核对正文与附件元数据，单封和会话卡片沿用各自的来源与取消边界。

支持 ImageIO 可识别的 PNG、JPEG、GIF、TIFF、WebP、HEIF/HEIC、BMP 和 AVIF 位图，按实际内容确定响应类型；SVG、PDF 及无法识别或无法解码的图片保留附件预览入口，不作为 CID 位图呈现。原图和预览均不设独立的像素高度或宽度上限，窄长图不因某一条边过长被应用拒绝。静态图在总计 1,600 万像素内保留原始显示字节；超过此预算时先检查原始元数据的总像素（不超过 6,400 万），再由 ImageIO 在后台生成有界预览，不预先创建全尺寸位图。预览尺寸由总像素预算和纵横比例推导，短边像素取整、方向及像素比例变换后再次复核实际面积；继续受编码字节预算限制，必要时有限次缩小，保持整张内容。JPEG 预览保留 JPEG，其余格式使用保留透明通道的 PNG；只替换本次呈现字节，不覆盖邮件原件或附件缓存。阅读器提示大图已缩放，附件入口仍可打开原图。动画与多帧图片也不按边长拒绝，仍检查帧数与累计像素，不自动丢弃帧变成静态图。

单图读取及同一正文的总字节、总像素预算仍有效；最多并行读取两张，同一 CID 的并发请求共用读取，一个等待者取消不打断其他等待者。最后一个等待者取消或切换邮件时取消底层任务，移除 WebKit 请求身份后才清理，迟到回调不能向已停止的请求写入。阅读器与 PDF 使用相同长图和缩略图路径；原生回归用合成长图验证首尾均保留，可显式指定只读本机图片路径复核实际附件，默认不读取用户邮箱。

处理器返回禁止缓存的响应，确保相同 CID 在不同邮件中指向各自的附件；仅切换来源而正文相同也会重新加载。失败在阅读器中显示数量、原因及重试入口，区分来源不可用、部件缺失或歧义、读取失败、格式不支持、数据损坏及超限；重试不绕过图片预算。顶部外部图片提示说明默认加载策略，不作为某张 CID 图片失败的诊断。页面离开时撤销在途读取，返回时重新创建来源。图片验证位于后台 actor，Core 不依赖 WebKit 或 ImageIO 的 UI 组合；JS、外部图片、追踪像素及自动导航的既有限制继续生效。

导出前显示本机完整报文与正文覆盖，可选择补全下载；选择器取消不创建输出。保存位置在下载前冻结，条件写入拒绝目录被替换、符号链接和同名文件被并发改动。批量结果清单逐项记录输出文件、来源或失败原因；取消保留已完成文件和清单。仅重试失败/未处理项先重新预检，再重新选择位置，不重放已完成项。

## 撰写附件与转发

附件由系统文件选择器或拖入操作授权读取。读取拒绝链接、硬链接和非普通文件；导入完成后草稿拥有文件名、类型、摘要及实际字节，不保存外部路径或跨重启文件授权。移除附件只修改本草稿。单个、总大小和数量受模型常量限制，选择的一批文件要全部验证成功才加入；取消丢弃本次未提交的读取。

草稿附件作为独立 BLOB 字段保存，转发的原附件状态也随草稿保存。旧草稿按空附件兼容；不合法或损坏的数据报错，不能静默丢掉附件后发送。备份包含附件字节，恢复前验证内容和大小；已投递或未知状态的目标草稿仍保留既有保护，不能被导入替换。

转发按固定来源邮件身份准备全部原附件，只在全部下载、读取和限额验证成功后提交到编辑器。失败或取消保持待准备状态并阻止发送，用户可重试，或明确选择不带原附件继续。原附件准备完成后，手动移除的项目随草稿保留，重开不会再自动加入。草稿右键另存为可以提取附件，包括投递未知或已投递锁定草稿中的留存数据，不改变投递锁。

发信前保存草稿并验证附件，完整 MIME 先序列化，再走原有 SMTP 领取与投递流程；密送只进信封。已发送副本保留该 MIME、线程引用及本地附件身份，正文缓存被淘汰后可从保留报文恢复，附件读取无需访问服务器。如果已投递但缺少已发送文件夹，保留已投递凭证和带附件草稿并锁定，不能静默清理或普通重发。新增入口不提供代理自动发送或绕过确认的路径。

## 本地归档与导入

账号来源由持久化 `sourceKind` 区分 IMAP 与本地归档，旧账号及旧序列化数据仍按 IMAP 兼容。本地归档没有网络端点、地址或凭据，不提供连接配置、同步、加载远端历史或缓存重建入口；协议服务在建连接与读取口令之前拒绝归档来源。数据层也拒绝对归档运行服务器文件夹对账及清空缓存。归档拥有独立账号身份和本地保留 UID；删除远端账号不会清理归档。

工具栏、邮箱菜单、空状态及账号菜单提供导入入口，拖入邮件文件或目录会先打开预览。系统选择器可选多个 EML、目录或 MBOX 文件；目录按层级导入，Apple Mail 风格目录中的 `mbox` 文件可被识别。读取以已验证目录句柄逐层进行，拒绝符号链接、硬链接和非普通文件；预览只保留有界元数据索引，文件授权与目录句柄仅属于当前窗口的来源会话，不持久化外部 URL 或授权。预览阶段不写库，确认后才创建或使用当前空间的本地归档。每批原件总字节、项目数、单封大小、目录和 MIME 深度均受限，超限提示分批处理。

MBOX 从固定文件描述符分块读取，只缓存当前记录及有界读取缓冲，不先装入整份邮箱文件；解码器可返回信封、报文起点、封装长度和实际变体，位置本身不含文件路径或访问授权。正文、信封行与块边界分离，支持二进制、跨块长行和取消。读取后核验文件及目录身份、长度和修改状态；中途变更会撤回该文件的全部候选，先前稳定文件不受影响。当前界面按记录保留位置、格式、原件长度和摘要；查看或导入时逐封读取并复核完整目录链、文件身份和原件摘要，不保留整批原件。来源总字节、索引元数据、项目数和单封大小分别有界；旧快照 API 的容量限制只用于兼容调用。

「MBOX 格式」可选择自动、mboxrd、mboxo、mboxcl、mboxcl2。自动模式在没有 Content-Length 时按 mboxrd 解引用；存在该头部时按正文字节数确定边界，正文含可能的旧式引用则要求选择确切格式，不猜测。mboxrd 解除 From 行及嵌套引用的一层传输引用；mboxo 和 mboxcl 只按旧式规则解除 `>From`，该格式自身无法区分某些原文引用，界面明确说明其限制；mboxcl2 不解除正文引用。格式依据见 [Dovecot 的 MBOX 变体说明](https://doc.dovecot.org/main/core/config/mailbox_formats/mbox.html)，不同站点格式的边界见 [RFC 4155](https://www.rfc-editor.org/rfc/rfc4155.html)。

Content-Length 必须是唯一、未折行的十进制正文字节数；重复、截断、溢出或边界不符的当前记录不发布为候选。按字节定界时保留正文换行及二进制，不把正文中的 From 行误判成信封；分隔填充不计入原件。明确选择 mboxrd 或 mboxo 时按相应信封规则读取，Content-Length 不控制边界。更改格式重新读取本次内存中的来源并重置勾选，不导入邮件；歧义出现时自动展开格式选项。预览、持久结果与 JSON 清单标明实际变体，旧回执缺少此字段时保持未知，备份恢复保留该字段。窗口主体可滚动，底部确认和关闭保持可达；Escape 沿用取消或关闭，关闭使在途读取和提交回调失效。

预览可逐封勾选，按来源文件夹和日期筛选，并选择或取消当前可见项；筛选不改变隐藏项的选择，界面明确显示已选数、可见数、所选原件大小与日期跨度。确认前冻结勾选身份，只将该集合交给原有事务导入流程；空选不创建归档，导入期间不可更改本次集合。无法读取的来源仍列明失败，不因未出现在可选邮件中而隐藏；重复判断继续在事务内复核。

文件夹映射按所选邮件的原始来源文件夹分组，默认保留层级；根目录邮件默认进入收件箱，也可统一到收件箱、选择已有归档中的实际目录，或填写以 `/` 分层的新路径。预览显示完整展示层级和归档名称，已有目录只列当前空间、当前归档内可接收邮件且祖先关系有效的文件夹；容器不能作为目标。未选目标、无效路径和过期目录阻止确认，切换归档不会默选替代目标；修改勾选、归档或规则会立即使旧预览失效。

映射预览仅在内存分配计划身份，不创建账号或目录，不保存外部授权。确认固定发起数据库连接、归档、所选原件摘要与目录链；新归档及系统目录与起始批次回执在同一事务提交。新路径在实际写入首封非重复邮件时创建并共用祖先，重复项不创建空目录、不移动已有邮件，也不改写原始来源文件夹和摘要的去重键。逐封事务重新核对目标及祖先，已使用目录被删除、改名或替换后拒绝继续，不自动重建或借用同名目录。关闭取消在途预览和迟到提交回调；重试未完成项必须重新核对当前映射。目录链随已确认批次保存，恢复时固定原目标身份，已创建目录的逐项凭证阻止删除后自动重建。

候选邮件可在二级只读窗口预览主题、地址、日期、正文和附件元信息，预览不创建归档、不写邮件或改变勾选。解析先由当前来源会话按索引读取并重新核对原件；来源丢失或变化时显示错误并要求重新选择；正文沿用禁用脚本和外部资源的阅读组件，此预览不读取 CID 图片或打开附件内容。关闭窗口取消解析与来源跳转，迟到结果不重新显示。

重复标记区分归档中已有的原件和本次来源中的另一候选；查看对应候选不会勾选它。查看已有邮件时重新核对归档、来源文件夹、摘要、原件长度、实际原件摘要和当前邮件归属，移动到同归档其他文件夹后仍可查看其真实位置。导入回执保存对应邮件及原件身份，事务内发现的重复项也记录实际匹配目标；旧回执未保留关联时明确提示重新选择来源，不按主题或 Message-ID 猜测。已有邮件删除、被替换或原件变化后拒绝跳转，备份恢复保留关联字段并验证合法性。

导入完成后主邮箱切到该批次范围，结果窗口仍保留回执、状态筛选和「查看本次导入」。该范围只查询本批实际创建且仍保留的邮件，排除早先已有的重复项；原件来源记录跟随同归档内的移动，删除及撤销移除相应成员，撤销时因变更而保留的邮件仍可查看。批次视图沿用数据库游标、正文筛选、保存筛选及全部匹配项导出，不限于首个文件夹或首屏。选择账号或文件夹可返回普通范围；历史回执也可重新打开批次，失效来源不改查其他归档。在邮箱中显示单封邮件先取得实际导航成功回执，失败保留预览及错误。

EML 保留完整原始字节。MBOX 按已确定的格式去除信封和传输引用，保留提取后的报文；无法安全识别的文件报告失败，不把错误文件显示成成功导入。带 Content-Length 的保留报文仍可原样导出 EML，现有 mboxrd 导出不会静默改写该头部，无法原样封装时提示使用 EML。重复判断使用归档身份、来源文件夹与完整原件 SHA-256；相同 Message-ID 的不同内容不会被合并。预览提示重复数，写入事务内再次去重，应对并发导入。

每封邮件的元数据、正文、附件信息、原件、来源和逐项回执在同一事务提交。`mail_import_batches` 保存初始清单和终态，`mail_import_entries` 按批次及项目身份逐封写回执，避免反复重写整份清单；未结束记录通过逐项回执核对已提交结果，不把它当作可自动重放的任务。取消保留已完成邮件并落最终报告，未处理项可在本次预览仍有效时重新核对后重试；索引批次也可在重新选择来源并确认匹配后继续原批次。历史报告及 JSON 清单只含相对来源名称、邮件标题与处理身份，不包含口令或外部授权。

索引导入的批次保存已确认邮件身份、相对来源、记录位置、格式、摘要和固定目录映射；不会保存外部 URL、书签或读取授权。历史回执提供重新选择来源入口，核对匹配、缺失、变化、多重匹配和已完成项；只继续匹配的未完成项，新出现的邮件不加入原批次。恢复继续使用原批次和项目身份，原件、来源与逐封回执在同一事务提交，保留撤销标记；每次领取生成新的运行凭证，旧预览及旧执行者不能覆盖新回执。恢复前再次核对批次及逐项回执快照，目录或原件变化不能自动改用替代目标。扫描显示已发现文件数且不伪造总量，解析显示文件与实际读取字节，写入显示所选项进度；结果可按失败原因分类查看。

导入历史可显式撤销本次导入。预览冻结该批次实际创建的邮件及其元数据、原件指纹；重复项不属于撤销目标。确认时重新核对当前空间归档、批次归属与目标集合，新增加的目标要求重新预览；预览后修改、移动或无法核验的邮件跳过。删除与 `mail_import_undos` 回执在同一事务提交，重复确认返回同一回执，不重复删除。撤销标记会阻止仍在运行的同批次导入写入及覆盖回执，避免取消后又出现新邮件；撤销历史随完整备份保留，不自动重放。需要重新导入时重新选择来源并生成新批次。

网络读取的显式取消会立即完成等待并请求断链，禁用超时计时也保留取消能力；单次恢复门闩避免成功、超时和取消重复回调，并清理多余看门狗。SMTP 在已领取投递身份之后被取消仍保留不可普通重发的草稿保护，取消不能证明服务器未收到邮件。

归档列表沿用搜索、多选、标记、移动、废纸篓和导出。正文缓存被淘汰后从归档原件重新解析，附件从同一原件按部件身份提取，无需原文件或服务器；发信使用当前空间可用的远端账号，缺失时明确提示先添加账号。账号列表向模型标明本地归档离线且不可发信；保存发信草稿及发送工具只选择远端账号，显式指定归档时在写草稿或连接前拒绝，不改变原有确认分级。删除整个本地归档须确认，操作只影响该空间内归档及其导入记录。

## 数据可携带性约束

导入默认落入当前空间本地归档，上传服务器属于独立的明确操作。本地归档与 IMAP 缓存必须有可持久识别的来源，缓存重建或服务器删除对账不能清掉归档。EML/MBOX 原件导出需要保留完整原始报文字节；解析后的文本与 HTML 不能证明原件完整。导出前核对邮件、正文、附件的实际缓存范围，失败列清单，不能把未下载内容计入完整导出。

后续变更在此更新实际行为及剩余范围；测试与构建结果以任务回执为准，不在长期文档记录测试数量或版本快照。
