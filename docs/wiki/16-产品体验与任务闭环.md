# 产品体验与任务闭环

本专项把产品审视中的建议逐项落实。验收以可达的用户流程、实际执行回执、空间隔离和恢复验证为准；不能以新增入口或通过局部测试代替端到端完成。

## 验收清单

- [x] 派生内容隐私：常用问句进入所属空间数据库；旧全局内容必须经明确归属选择迁移；后台联网说明准确。
- [x] 完整备份：覆盖知识、智体、邮箱、定时、MCP、应用及项目资料；密钥不导出；具备覆盖清单、恢复点、预检、失败回滚和恢复核对。
- [x] 首次成果：选实际任务、完成必要配置和连接验证、选择资料、检查首份成果，进度可恢复。
- [x] 邮箱完整度：同步范围可见、更早历史可加载、缓存可重建、远端删除和标记可收敛；检索说明实际覆盖。
- [x] 每次任务：保存各次运行，按待处理/进行中/完成查看，并聚合当前空间的对话、协作、定时和后台作业。
- [x] 一致成果：文件工具、Python、Shell 的真实产物均可发现；保留来源、版本、预览、导出和继续修改。
- [x] 操作可达：问句快捷选用、同空间统一搜索、资料引用和动作入口；输入区高级选项按需展开。
- [x] 知识生命周期：扫描件 OCR、批量导入预览、重复检测、来源更新和失效提示，失败可重试且不会覆盖用户编辑。
- [x] 定时闭环：对话草拟与预览确认，结果可继续追问/生成报告/保存知识，支持变化提醒，运行与错过语义清楚。
- [x] 可见预算：任务时间和 Token 上限、预算耗尽后的处理、可配置价格与费用估算，不把未知用量当零。
- [x] 项目连续性：同空间工作区绑定项目说明、知识范围和常用技能；本轮可排除记忆，不扩大文件授权。
- [x] 场景复用：技能和小应用具有真实任务模板、输入示例、试运行与可验证输出标准。
- [x] 本机衡量：首次有效成果耗时、成果后续使用、人工介入与完整恢复验证按空间记录，用户可以查看和清除。

定时闭环已通过纯草拟、预览取消/确认、旧回执重开、稳定观察的静默基线与变化通知、结果落盘后通知、失败只补存和跨空间取消保护验证。原生回归运行模型协议夹具与真实文件工具，核对报告仍需普通批准，知识先编辑再保存；独立签名宿主进一步检查三次连续观察、预算编辑、比较值、知识回执、独立待发草稿及原附件保留、预算失败的部分正文。任务预算覆盖 Token、工具次数和含组装的截止时间，用量未知与真实零分开，匹配价格才估算费用；新增字段通过备份恢复兼容验证。完整回归、正常签名构建和严格签名校验通过，最终三语文案经原生复核，定时闭环与可见预算项已完成。宿主仅使用临时库与模拟只读结果；App 退出后运行、无人值守写入和月度总费用封顶仍不属于当前能力。
