# UI 层

`AgRoom` 提供应用入口、菜单栏和全局热键；`AgRoomUI` 提供 SwiftUI 功能页、浏览器与本地化。UI 通过 `Hub` 和明确的组装点访问 Core，不直接操作 GRDB。

## 应用入口

App 根创建全局唯一 `Hub` 并注入 `RootView`。`AppDelegate` 处理菜单栏状态项、主窗口唤起和全局热键。主窗口使用有稳定身份的单一 `Window` Scene；关闭后经 `openWindow` 重建，查找时不回退到邮件或小应用窗口。语言切换通过 `LanguageManager` 触发界面重建。

菜单栏机器人沿用应用图标中央的造型，去掉外围圆环与节点。基础自定义 SF Symbol 保存在 App 的 `Assets.xcassets/AgRoomMenuBar.symbolset`；动态表情由 UI 层 `MenuBarRobotDrawing` 提供固定画布的透明矢量模板帧，App 层 `MenuBarRobotController` 缓存与播放，菜单栏占用固定宽度，切换状态不挤动相邻项目。

打字态作为垂直对齐基准；其余表情在原画布内下移 2pt，补偿没有双手和键盘时的底部留白，睡眠与等待提示随表情一起定位。画布尺寸、打字帧和菜单栏点击区域保持固定。

- 待命偶尔眨眼；无任务且无应用内交互持续一分钟后闭眼休息，缓慢呼吸并间歇显示 `z`；工作时双手交替敲击。未配置启用模型时使用叉眼；等待人工确认、输入或守护任务恢复时停手并显示提示标记。等待处理优先于工作，工作优先于未配置与闲置。
- 聊天来源独立于退出移交判定：弱引用已加载模型，只汇总工作/待处理标记，覆盖非当前会话及自动审核，不共享空间服务或会话内容。另订阅定时运行、守护执行与后台作业；普通扫描和轮询不会被算作工作。
- 提供商配置提交后通过无载荷通知刷新全局配置摘要，只判断启用项是否包含端点与模型，不读取 Keychain、不发起连接测试；暂时读取失败保留已知状态。该表情不代表远端实时连通性。
- 通用设置提供动画开关；系统「减少动态效果」、菜单展开或屏幕休眠时停止帧调度，保留静态状态表情。待命只在眨眼时更新，工作/睡眠使用低频离散帧；状态文字与辅助功能名称走三语本地化。任务完成、应用重新激活及应用内键鼠操作会重新计算闲置时间。

Daemon 作为 App 内嵌工具 target，用于用户允许的退出后续跑。启动、交接和结果恢复由 `DaemonSupport` 与 Core 快照协议衔接。

## RootView

聊天输入区常驻「目标」开关，选中后直接将输入框文字发送为目标，自动生成名称，不设目标预算；成功后恢复普通对话，失败保留草稿，待设定状态不跨会话继承。「更多选项 → 目标高级设置」承接自定义验收与约束，会话顶部卡片承载进度、暂停、结束、逐项验收及保存重试；任务中心的「目标」入口按空间分页打开来源会话。目标段复用聊天宿主而不改变工具批准语义；具体状态与恢复限制见 [目标执行](19-目标执行.md)。

`RootView` 使用分栏导航承载各功能页。主侧栏按「常用、资料、能力、系统」分组，「能力」内依次为「协作、智体、技能、定时」；数据库入口「数据」归入「资料」，简繁中文的入口和分组名均保持两字；英语保留自然的完整名称。导航行使用可键盘操作的按钮，选中项直接决定显示页面，不再维护第二份延迟显示状态。

主侧栏在完整导航与 64pt 图标窄栏之间切换。唯一的自定义工具栏按钮、菜单与 `⌥⌘S` 共用展开状态；展开 / 收起偏好通过 `@AppStorage` 保存，重开窗口、重启应用或切换语言后恢复上次选择，首次默认展开。`SidebarNavigationLayout` 使用 `NavigationStack` 承载工具栏，以同一个横向布局管理侧栏和详情：侧栏宽度、详情位置与两种导航的透明度共用 260ms 缓入缓出动画，避免原生列收起与额外图标栏插入的时序差。系统「减少动态效果」开启时直接切换。两种导航及当前功能页保持挂载，隐藏的导航禁用交互并从辅助功能树移除；快速反向切换沿当前动画位置继续，保留页面、草稿与导航滚动状态。按钮固定安装在窗口工具栏，不随切换重新挂载。该全局布局偏好不携带空间内容，自动布局模式不覆盖用户选择。

窄栏复用原有导航目录、选择动作与协作待审批角标，分组用分隔线区分，图标悬停显示名称，高度不足时可滚动。顶部以当前空间的图标和强调色标识归属，点击仍经 `SpaceStore.switchTo` 切换空间；收起操作不改变当前空间或页面。

空间切换必须触发空间相关界面重建。聊天与邮箱模型当前按空间缓存，切走不等于释放旧任务；缓存模型只能使用固定空间的依赖，迟到回调不能从可变的当前空间取服务。聊天自动记忆与审核目录仍有待修复遗漏，见 [专项审查 A01](reviews/2026-10-10-稳定性性能与架构审查.md)。新增全局状态前，先确认它是否会携带空间数据；如果会，就不能作为跨空间单例保留。

数据库不可用时（打开或迁移失败）`RootView` 展示覆盖层：失败原因、数据库文件路径，以及「在访达中显示 / 打开备份文件夹 / 重试」入口，而不是让各功能页在后续操作里随机报错。

工具栏的页面筛选只在当前页支持列表搜索时显示；设置、帮助、用量等无页内搜索语义的页面不占用工具栏位置。独立的「搜索与操作」按钮及 `⌘K` 打开当前空间的统一入口。结果可按资料类型过滤、分页、预览、打开来源或加入待发草稿；输入 `>` 查找常用导航、新对话、首次任务与任务中心等操作，回车可打开当前结果或执行首个匹配操作。搜索不会发送消息或执行资料中的指令，停用资料不会因搜索而启用。

来源跳转携带实际记录身份：对话定位到消息，知识定位条目，记忆/智体/技能打开所选记录，小应用沿原有窗口入口打开；邮件先解析实际账号和文件夹，较早邮件作为独立定位项加入列表，分页游标仍来自正常列表页，不能跳过中间历史。定时、协作、后台作业及成果也能打开初始页之外的指定记录或版本。搜索面板关闭后才应用后续路由；切换空间清理待办路由和面板，异步查询、预览与引用丢弃过期结果。

## 分栏布局与窗口约束

主窗口标题栏的空白区域支持双击，在标准放大尺寸与原窗口大小之间切换，使用 AppKit 标准缩放恢复原来的位置和大小。命中区域按窗口当前内容布局边界及工具栏视图实时判断，排除交通灯、工具栏按钮与搜索框；单击和拖动仍交给系统处理。监听仅绑定主窗口，根视图卸载或移出窗口时移除，全屏及显示附属表单时不触发缩放。

主窗口使用统一窗口工具栏，隐藏标题栏中可见的应用名，保留窗口的语义标题、交通灯与唯一侧栏切换按钮。侧栏按钮使用窗口最前方的工具栏槽位，避免随侧栏分隔线移动；工具栏使用窗口背景色，展开与收起侧栏时保持一致。标题栏下的分隔线由 `RootView` 在整个分栏容器顶边叠加明确的水平单像素线常驻绘制，横跨完整侧栏、图标窄栏与详情区，不参与点击命中或辅助功能导航。此处不用方向依赖布局环境的 `Divider`，避免在分栏布局中出现贯穿页面的竖线。App 层在窗口挂载和根视图更新时将 `NSWindow.titlebarSeparatorStyle` 设为 `.none`，避免系统效果与自绘细线重复。`.searchable(placement: .toolbar)` 只负责搜索控件；即使请求系统 `.line`，也不能依赖工具栏布局始终显示分隔线。新建窗口、空间切换和语言切换后的根视图重建共用此布局。

`HSplitView` / `NavigationSplitView` 的列在拖拽分隔条或窗口改尺寸时，会在 AppKit 的布局 / 更新约束途中回调 `onGeometryChange`。**这类布局回调里禁止写任何观察态**（`@State`、`@AppStorage`、`@Observable`）：写入会让 SwiftUI 在同一趟更新里再次请求更新约束，窗口在一次显示周期内的 Update Constraints 轮次迅速超过窗口内视图数，AppKit 抛异常并 `abort()`。

- 断言原文（`log show --predicate 'process == "AgRoom"'` 可见）：`NSGenericException: The window has been marked as needing another Update Constraints in Window pass, but it has already had more Update Constraints in Window passes than there are views in the window.`
- 崩溃栈特征：`_postWindowNeedsUpdateConstraints ← setNeedsUpdateConstraints: ← NSHostingView.setNeedsUpdate ← SplitViewChildController.hostingView(_:didUpdateMinSize:maxSize:) ← NSHostingView.SizeConstraints.update(from:)`；同一循环还会出现工具栏 `_NSConstraintBasedLayoutHostingView` 的 `invalidateSafeAreaInsets` 与 CoreAutoLayout 的 `_noteValueOfVariableChanged` 两条无效化路径。
- 页面从 `UserDefaults` 读取列宽作为初值。`SplitDivider` 以起拖时的列宽和窗口坐标中的鼠标位移计算新宽度。分隔线在悬停、拖动和松手时保持相同的颜色和粗细，鼠标进入命中区时显示系统的栏宽调整光标。
- 松手时按最终鼠标位置更新列宽，并由 `SplitColumnWidth.persist` 保存。窗口缩放、页面切换和可用宽度不足时的自动挤压只影响显示。
- `HSplitView` 的页（聊天、邮箱、技能、智体、文件、技能编辑器）统一改用 `GeometryReader + HStack(spacing: 0) + SplitDivider`：拖动期间只更新显示宽度（`@State`），拖动结束写一次偏好。可见宽度由 `SplitWidths.resolve` 按容器实际可用宽度分配：先满足各定宽栏，剩余给弹性栏；空间不足时按定宽栏的「多余量」比例压缩其**本次显示宽度**，尽量保住弹性栏最低宽度，被压缩的结果不写回偏好。
- 聊天页拖动会话栏或固定右栏时，分隔线、标题栏和输入区实时跟随。消息滚动区沿用起拖时的正文宽度，超出视口的部分临时裁切，手势结束后按最终宽度重新排版。整个过程沿用同一份消息视图、选区与草稿。
- 主侧栏分隔条在展开时可拖拽，以 `@GestureState` 保存手势位移，结束后只更新当前窗口的展开宽度，不从布局回调写状态，也不持久化宽度。初始宽度由 `RootView.sidebarWidths` 按当前界面语言提供：简繁中文默认 160pt、可在 140–220pt 间拖动；英文默认 200pt、范围 190–260pt。收起后再次展开沿用当前窗口的拖拽结果。导航文字保持单行，空间不足时截断并通过悬停显示完整标签。窗口最小宽度（`RootView` 的 1120）作为外层约束保留，不应靠继续增大它来解决内部多栏竞争。
- 主侧栏由自管容器绘制，不创建原生可收起列，避免系统按钮与显式按钮竞争状态。工具栏提供唯一显式按钮，应用菜单替换默认侧栏命令，两者共用 `SidebarVisibilityAction.toggle` 修改持久化绑定。动画只由展开状态触发，窗口缩放和分隔条拖拽直接布局。原生宿主夹具采样双向过渡的中间位置，检查无反向跳动或越界、减少动态效果、按钮唯一性、快速切换、草稿与详情身份；最终布局还须在实际 App 窗口复核。
- 布局实测值里「不上屏」的部分放非观察态暂存盒（如 `ChatScrollState` 的几何快照与跟随意图）：写进 `@State` 等于每次布局回调都让宿主视图重算 body。滚动几何统一从 `onScrollGeometryChange` 取内容高度、视口高度、偏移与底部 inset，不分别测量内容底边和视口底边再跨布局时刻比较。
- 布局实测值里必须上屏的部分（如「回到底部」按钮、图片适尺寸缩放比）先比较再赋值，并延后一拍写入（`Task { @MainActor in ... }`）。
- 禁止的形态：`onGeometryChange` 把实测宽度写回参与布局的状态（几何 → 状态 → 理想宽度 → 几何 是不收敛的反馈环），或写回会被 body 读取的 `@AppStorage`。
- 周期性后台状态只在实际变化时赋值：`@Observable` 的 setter 无条件通知观察者，定时轮询里无条件赋值会让根视图持续重算 body，为上述循环提供入口。

## 定时任务闭环

会话中的 `schedule_draft` 显示不会自行创建或启用任务的草稿回执卡片，预览进入 `ScheduledTaskEditor`。编辑器常驻显示所属空间、下次时间、任务预算、App 运行限制和总开关状态；指令、规则、时区、预算、通知与稳定比较标准可编辑，只有明确保存才创建定义。重复打开已保存回执定位现有任务，取消不写入。

定时页和任务详情共用结果信息与操作组件：显示本次预算、耗尽原因、部分内容、变化状态/比较值及用量完整性；完整用量和身份匹配的价格才估算费用。继续追问和生成报告新建待发草稿并保护原输入，报告文件仍走正常批准；保存知识先编辑预览再提交。所有操作重新读取来源并核对固定空间。终态保存失败显示重试保存且阻止重跑；菜单栏提示需处理，重试只补回执。主开关重新启用跳过停用期间的时间，App 原已启用的离线时间仍按宽限补算。

## 聊天状态

重试旧回答与编辑旧问句共用历史准备入口。它固定来源空间、会话恢复版本和目标消息 ID，补齐历史后再次定位。Core 复制消息、回答版本、记忆排除设置及来源任务引用，按新消息 ID 重建上下文报告。首次保存完整前缀并校验来源版本后，宿主才启动新一轮。

输入区的思考菜单和设置页显示所选模型实际可用的档位。每条回答的上下文详情列出本次输入预算、最后一次请求的回复上限和思考设置。GPT 返回的进度文字在过程区显示，最终回答单独呈现。

聊天显式选择图片模型时，结果按发起轮的固定空间保存到内部附件目录，并复用助手气泡的图片预览与保存入口。保存目录逐级拒绝符号链接，不能写入另一空间或用户工作区。图片随回答版本保存，重试时清空本次预览，切换旧版本时恢复对应附件；备份包含所有版本的图片，恢复时同步重写路径。自动标题继续使用本地问句回退，不额外调用图片模型生成图片。

失败重试与末轮编辑重发复用原回答的消息身份及时间戳；错误角色转回助手时也必须显式保留这两个字段。每次新执行分配独立任务身份，旧回答版本保留原任务身份，版本切换不重新运行任务。保存失败仍保留内存状态并在模型请求前停止；历史分支继续使用独立的会话与消息身份。

自动标题在已完成问答上生成，不要求会话恰好只有两条消息，排队续发不会跳过命名。生成前先按首条问题保存有意义的短标题；模型返回空正文、失败或只返回思考时保留该标题，不把「新对话」固化为正式名称。旧的三语占位标题在下一次完成问答时也可更新。标题请求使用快速思考档和足够的输出预算；生成结果仍校验应用语言、长度与占位内容。后台写回在同一空间库内核对原标题及恢复代际，不能覆盖手动重命名、删除或恢复后的会话。

工作区菜单和输入区高级选项提供「项目说明与资料」，以「项目资料」和「MCP 工具」页签统一承载项目上下文与外部工具。项目资料中的说明、全部/指定知识库及常用技能保存到该空间工作区，切换页签保留未保存编辑；MCP 配置仍由当前空间的所有工作区共用，通过「管理 MCP 服务」单独保存，下轮生效。无知识库选择时明确说明不使用知识，过期选择显示可移除条目，停用技能不能新增为偏好。当前工作区有未结束任务时项目资料只读，竞争保存提示刷新，关闭或切空间的迟到回调不得更新新界面。输入区显示项目摘要及下一轮/当前轮排除记忆状态；实际请求与任务历史可回看运行使用的配置快照。修改设置和打开入口均不改变原草稿、附件或文件授权。

首次引导以资料整理、资料对比和邮件摘要为真实任务入口：选择目标、显式验证模型连接、准备文件或示例资料，再进入正常对话执行。连接测试产生的少量模型用量如实记账；模型配置或凭据变更会立即撤销验证，重载期间禁用连接测试；读取失败后清空旧候选，仅通过重新读取配置恢复，避免旧端点使用更新后的凭据。取消、换空间和过期回调不能重新标记成功。任务、模型选择、示例开关、资料名称和开始时间按空间保存；重启需重新验证连接并重新选择外部文件，不恢复文件授权。邮件摘要先读取当前空间已启用账号及本地同步邮件的数量，没有来源时引导前往邮箱配置与同步，不发起后台同步。

首次任务的新手提示只面向当前空间尚未成功完成任务、也未跳过引导的用户，空对话中提供入口。跳过或关闭引导、成功完成普通任务或确认首个成果后，空间内隐藏状态持续保存；删除会话、清除统计不会重新提示。启动弹窗等待空间状态读取完成，已有成功历史的用户不再自动进入；未完成引导保留继续与成果检查，不重新弹完整设置。统一搜索与操作中的首次任务命令始终允许手动打开。

启动前先保存原来的未发送会话，再保存独立任务会话与进度，随后沿用既有工作区、发送和审批策略。保存或引导资料导入失败时停止自动发送并保留草稿。成果检查读取真实回执中的全部成果，保留版本可在原文件删除后完成检查；旧路径只接受本会话已登记的主目录和引用文件夹。最终回答可能先于引擎空闲状态保存，成果检查须在运行转为空闲时再次触发，不能只依赖正文或产物变化。确认前重新核对可用内容、会话与运行身份，再原子保存用户的有用确认及本机耗时。聊天空态按上述规则提供引导入口，未完成进度可返回原会话继续；删除该会话会清理恢复入口，旧版本留下的悬空进度不会阻止用户手动重新引导。

常用问句从会话所属空间数据库读取，在输入框上方可横向选用；点击只填入草稿，由用户检查发送。设置页维护同一份空间列表，推荐生成固定使用发起空间的会话、模型记账和保存服务；旧全局列表必须由用户选择归属后迁移。界面通过不含内容的变更通知刷新各自空间的快照。

对话输入区的常用问句、任务预算和模型单价由页面任务统一刷新，全部读取成功后才替换界面快照。离开页面、切换空间、刷新被新请求取代或取消时，旧结果与错误均失效；正常取消不写入缓存聊天模型的弹窗状态。真实读取失败保留上次快照，显示覆盖这些偏好的本地化提示，诊断日志仅记录错误类型和代码。

输入区的「引用资料」打开同空间搜索；加入时重新核对预览版本与捕获的会话，只追加待发文本，不替换原草稿或附件。第一行常驻模型、模式、工作区、权限、思考力度和累计用量；「更多选项」展开第二行，容纳记忆排除、项目说明与资料、任务预算、项目配置摘要和上下文压缩。MCP 工具入口归入「项目说明与资料」，不再单设闪电按钮。项目配置摘要与其他展开选项同行，两行在窄窗口均可横向滚动。

输入区提供任务预算入口，显示新一轮的总 Token 与时间上限，并可限制工具调用数。前台、子代理与审核沿用同一账本；确认恢复与 daemon 移交保持已消耗额度和原截止时间，时间包括等待审批。额度不足时停止新请求并保留已有成果，界面说明如何检查记录、调整预算与明确继续。配置单价后可显示按较高普通费率计算的保守上限估算，不把 Token 上限解释为账单承诺。

聊天界面负责：

- 会话摘要和按 seq 分页加载的消息；明确的「加载更早消息」入口。空闲历史按访问顺序和内容预算淘汰，运行中、挂起中或保存失败的本地状态不淘汰。后台刷新不会替换这些本地状态，也不会删除请求期间刚创建的会话。恢复完成时只使版本变化的会话运行失效并重新读取。
- 会话列表按工作区分组；点击工作区标题可收起或展开其下的对话与空态，标题行的操作菜单和新建对话按钮始终可用。折叠状态按空间随聊天模型保留，搜索期间临时显示匹配对话，清除搜索后恢复折叠；在工作区新建对话会展开该组。操作菜单提供「引用文件夹」「在 Finder 中显示」「归档」（已归档视图下为「恢复本工作区」），非默认工作区另有「移除工作区」（需确认）。引用文件夹通过系统选择器添加，可多选；只移除引用，不删除目录。该工作区有运行中或挂起任务时不能修改引用。底部工作区下拉只保留切换、新增与添加已有工作区。
- 工具等待人工批准时，所属会话在日期右侧显示橙色「待批准」，宽度不足时显示盾牌图标。切换对话后标记仍留在原会话，批准、拒绝或停止该轮后消失。
- 对话中的 `workspace_folder_draft` 只生成绑定本轮空间、工作区与会话的只读请求回执，不接收模型指定的目录，也不扩大当前运行的工具范围。任务结束后，原生回答的成功工具轨迹可显示目录请求卡：固定授权说明与可信的空间/工作区名称在前，模型理由标为未核实。用户点击后由系统选择器一次选一个目录；选择器返回时再次核对当前空间、会话、消息当前回答版本、运行与回执身份、工作区主目录身份和无阻塞状态，才把所选目录登记为该工作区引用。取消、切换上下文、旧选择器回调或复制回答都不登记；成功后同一卡禁重复提交，引用从下一轮装配生效，可在工作区文件夹管理中移除。
- 分组保留空工作区（默认工作区恒显示）：工作区即使没有对话也显示标题与两个按钮，空态显示「暂无对话」；因此新建入口统一收敛到标题行，不再单设「新建对话」按钮。
- 「新建对话」与 ⌘N 共用创建流程：标题行按钮归属该工作区（跨工作区新建不影响原会话归属），⌘N 使用当前/预选工作区、无选择时用当前空间默认工作区；新建后切回「当前对话」视图、清除搜索并把焦点移入输入框。失效工作区禁止新建并提示先恢复目录，不静默改用默认目录。对话不再提供聊天/编码选择、右键切换或模式角标。每轮自动判断工作流，同一会话可连续处理不同领域任务；最近解析的内部工作流仅用作短续问提示，新会话从通用提示开始。权限预设仍独立可见，意图判断不会替用户更改权限。
- 会话列表筛选（「对话」标题右侧菜单）在「当前对话 / 已归档对话」间切换。归档按工作区批量执行（不受搜索、隐藏、置顶筛选影响，工作区保留且仍可新建），确认框显示工作区名与对话数；无对话可归档时菜单项禁用。单会话与批量归档在实际提交时共用阻塞门禁，同时检查运行映射、持久待确认/待提问快照、待发送队列和后台执行，避免重启恢复空档或确认弹窗停留期间新任务被归档。已归档列表可查看并支持单个或按工作区恢复。
- 会话列表与详情共用同一套选择规则（`ChatViewModel.eligibleSessions` / `reconciledSelectionId`）：候选集合由「归档状态符合当前列表模式」与「隐藏状态符合『显示隐藏对话』设置」共同确定，排序沿用列表的置顶优先、更新时间倒序。所有会改变候选集合的入口（启动加载、删除、隐藏 / 取消隐藏、归档 / 恢复、切换当前 / 已归档、开关显示隐藏、返回聊天页与切换空间、后台刷新）都调用同一校验：当前选中仍有效则保留，失效则取候选首条，无候选则置空显示空态；仅在选中 ID 实际变化时才赋值。列表模式（`sessionFilter`）与隐藏显示快照随 `ChatViewModel` 按空间保留，因此切换功能页返回时列表与详情看向同一份规则，不会出现「列表回到当前、详情仍是已归档」；完整重启后模型重建，默认进入「当前对话」。隐藏 / 归档走乐观更新，落库失败只回滚本次仍然有效的元数据修改并再次校验选择，迟到的失败不抢回用户随后主动切换的选中项。
- 删除会话先阻止该会话新发送并等待已在途保存结束，数据库删除成功后才从列表清除会话、草稿、附件与待发送项；失败时保留这些内容并显示可重试的三语提示。若删除时本地任务正在运行，尝试删除会先停止该轮；删库失败不会自动恢复已停止的执行。
- 搜索只是候选集合上的临时过滤：输入检索词时保留当前详情与草稿，点击结果才切换（避免输入过程中不断跳转）；搜索无结果时提示「没有匹配的对话」，与「暂无对话」区分。新建对话按钮与 ⌘N 清除搜索、切回「当前对话」并选中新会话，列表与详情使用同一份归档、隐藏候选集合。
- 会话首轮完成后按应用语言设置生成短标题（system 跟随系统语言），与独立的 Agent 回复语言设置无关。中文标题至多 12 字，英文标题至多 6 词；模型输出语言不符或为空时重试一次，仍失败则使用当前语言的通用标题，不沿用问句原文。
- 草稿、附件、发送队列和当前运行。
- 流式正文、思考和轨迹的节流更新。
- 思考过程默认收起，用户切换后保持其展开选择；标题不显示推理用量。模型返回的推理文本与工具轮叙述在同一区块展示；没有可见文本时不显示空区块。运行回调核对会话和运行身份，终态使用引擎完整思考记录覆盖流式预览，避免重复追加中间叙述。
- 工具确认、结构化提问与恢复。
- 引擎构建、停止、重试、编辑和持久化。
- 右侧面板把「内容状态」（轨迹是否有内容、浏览器是否有标签）、「显示状态」（`RightPanelMode`：关闭 / 浮层 / 固定分栏）与「当前页签」分开：工具产生第一条轨迹只更新入口与数量提示，Agent 启动浏览器自动打开浮层，用户点击轨迹 / 浏览器入口打开浮层，只有主动「固定到右侧」才改变三栏宽度。已固定的面板在内容暂时为空（新一轮无轨迹、切到无轨迹会话）时显示空态，不因内容为空整栏消失。
- `ChatSplitLayout` 在三栏可用宽度不足时将固定右栏临时显示为浮层。窗口恢复足够宽度后回到固定形态。浮层按可用空间调整宽度，覆盖在对话区上方。
- 识别明确的新技能需求，在对话区先展示生成意愿确认，再通过 `skill_create` 进入生成与写入确认。
- 同一会话完成 10 轮问答后，一次性询问是否将对话沉淀为技能。
- 参与方徽章、轨迹面板与轨迹详情按轨迹显示本轮涉及的智体与技能：智体工具名（含子代理的 `> 内层工具` / `→ 内层工具` 后缀）通过当前空间智体库换成昵称，无昵称回退名称、再回退工具名 slug；技能 alias 优先，无 alias 回退技术名。显示名按 TTL 缓存，改昵称后无需重启生效。

### 聊天自动滚动

滚动状态由 `ChatScrollState` 单独持有，与可观察 UI 状态分离：`isFollowingBottom` 表示是否随新消息与正文高度保持底部，`showScrollToBottom` 只表示回底按钮是否可见，两者不再互相代理。待执行滚动请求、当前会话 ID 与请求世代也放在这里；观察态只在延后一拍的主线程任务里同步。

- 几何回调只更新快照并合并请求，不直接写 `@State`。初次布局数据无效（内容或视口高度为 0）时不改变跟随状态；亚像素变化不重复排队；内容增高、窗口缩放、输入框或确认卡改变视口都不被解释为用户上翻。内容高度骤降（如正文转入折叠思考区）导致偏移越过新底部时，跟随状态下补一次无动画校正，避免下方残留空白；内容短于视口时由短内容底部对齐负责。
- 只有 `onScrollPhaseChange` 报告的跟踪 / 交互 / 减速阶段，且偏移确实向上、距离底部超过暂停阈值（120pt）时才暂停跟随；回到 64pt 内恢复跟随。回底按钮的显示距离（400pt）独立判定，不影响是否自动跟随。程序自身滚动与动画滚动不算主动上翻。
- 所有入口（新消息、流式正文增长、排版完成后的高度变化、回底按钮、提问卡出现）统一进入滚动请求队列，同一轮布局只排一个收尾任务；自动校正无动画，新消息与回底可保留短动画。任务执行前核对会话 ID 与请求世代，并复核当前是否仍跟随、未交互、未处于程序动画；用户已接管滚动时丢弃迟到的自动请求（显式回底除外）。执行后由新的几何回调复查，未到位才继续校正，已到位立即停止。
- 消息列表中每条消息的气泡与附属内容包在同一容器内并使用消息 ID。底部锚点包含最后一条消息下方的留白，自动跟随与回底按钮都能定位到实际内容底边。会话内搜索仍按消息 ID 定位，并在定位时暂停跟随、作废在途回底，避免下一段流式输出把用户拉走。
- `.defaultScrollAnchor` 按角色拆分：只设置 `.initialOffset` 与 `.alignment` 为底部，负责初始位置和短内容对齐；尺寸变化后的跟随统一交给滚动状态机，默认锚点不再参与。
- 会话切换时滚动区按会话 ID 重建，`ChatScrollState` 同时重置几何、跟随与在途请求并递增请求世代；离开页面调用 `invalidateRequests()`。旧会话迟到的解析或滚动回调因会话 ID / 世代不匹配直接丢弃。异步富文本排版（Markdown、图片、公式、图表）只通过实际高度变化触发校准，不增加逐段滚动回调。

待发附件有三个入口：文件选择面板、拖放文件到输入区、在输入框内粘贴剪贴板中的文件或图片。三者都汇入当前会话的待发列表；切换会话时保留各自的文本和附件，发送时才落地到空间附件目录。

已发送的用户消息按「图片、文字气泡、普通文件附件、操作栏」从上到下排列，整组靠右对齐。图片独立展示圆角缩略图，不套文字气泡的蓝色背景；多图沿用自适应宫格，点击仍打开图片浏览器。纯图片消息不生成空文字气泡，历史消息采用同一布局。

消息操作栏只显示图标与数字：复制、重试、编辑重试和参考入口使用图标，工具轨迹入口保留调用次数，↑ 表示输入 Token，↓ 表示输出 Token，生成速率使用闪电图标与数值。操作名称、Token 含义及速率单位、实时或本轮平均状态通过三语悬停提示和辅助功能标签提供。

会话标题栏与输入框下方沿用消息的箭头，显示会话累计的输入、输出 Token。标题栏有工具轨迹时，入口显示列表图标和调用次数。

主侧栏导航使用 18pt 单色线条图标（置于 28pt 对齐区域内）与 15pt 文字，常态常规字重、选中态中等字重，去掉图标底块；未选中图标采用系统次要文字色，选中时随高亮行变白，并为导航行保留充足的点击高度。

输入区底部的模型、思考力度、工作区、权限入口与累计 Token 统一使用 14pt 字体和常规尺寸控件，空间充足时作为一组水平居中；窄窗口或名称较长时改为横向滚动，保持文字与控件的固有尺寸。用量紧跟设置项。无活跃会话或暂无用量时，底栏显示「↑ 0 ↓ 0」。底栏不显示生成速率；助手消息操作栏在复制、重试右侧显示本轮速率：流式输出期间为实时速率（工具执行与等待人工时隐藏），结束后换成当前轮已观测流式区间的加权平均，其后跟随本轮输入/输出 Token，下一轮开始时清空。实时估算带近似标记；测速按会话与运行隔离，迟到快照不能覆盖较新数据；不计排队、首个输出前等待、工具执行和人工等待，无有效流式区间时不展示速率。该指标仅保留在本次界面的会话状态中，不作为计费或服务端性能承诺。免责声明在下一行独立居中。

输入区底部的权限按钮采用 DeepSeek Harness 的单一预设菜单：只显示当前预设名称与下拉箭头，选择器共用目录与切换入口。菜单包括「仅可查看 / 工作区内修改 / 扩展访问 / 自动审核」，自动审核标记实验性；历史不匹配组合显示为不可选择的「自定义」。范围与审批开关一起保存，成功后发布；保存失败保留原设置。运行、挂起、后台执行与保存期间锁定整个选择器。自动审核和扩展访问每次切入均需勾选风险说明后启用；切换会话会撤销旧确认。默认值目录不包含自动审核，新会话不会继承刚查看的历史会话授权。文件与空间围栏、高风险确认仍由既有机制执行，完整语义见 [12-权限模式](12-权限模式.md)。

「脚本与权限」页面从权限浮层或设置页打开，固定绑定当前空间：会话权限、执行确认、授权规则、执行记录四区。会话入口携带当前会话上下文；设置入口只展示新会话默认值与本空间规则/审批记录，并在有会话待确认时提示回到对应对话处理，不聚合其他会话的参数。规则读取区分缺失、解码失败与不可用；撤销失败不从列表移除。规则读取、撤销和清空失败只显示三语的修复与重试建议，不展示底层文件路径或原始错误；日志仅记稳定失败类别或脱敏类型/码。任务文件恢复按文件已变更、丢失、无旧版本或身份不匹配给出处理提示；恢复点不可用可直接重试，失败不伪装成成功。审批记录明确标注「不代表执行成功」且首期不含逐次执行结果与会话关联。

自动审核随权限预设按会话保存，运行和挂起期间不能切换；停止、撤销或换轮时作废在途审核结果。确认卡显示保留人工的具体原因（关闭、硬确认、代码执行、范围无法核验、内部确认或重启恢复限制等），原因随确认快照持久化并使用三语本地化。自动批准只消费审核所指的队首调用；其他队列项继续按规则判定。审核结束恢复执行前再次校验运行身份和设置世代，停止或切换后的旧结果不能执行工具或清除新审核状态。

运行状态必须绑定稳定的会话、消息和 run 身份。每次发送（或挂起后原地续跑）建立独立 `ChatRunContext`（持有引擎、任务、流式缓冲、轨迹）并分配 `ChatRunID`，由 `ChatRunState` **按会话**持有各自的运行槽：所有引擎回调携带 runID，投递前校验身份，旧运行的迟到增量与轨迹被丢弃；运行收尾只清理自己会话的上下文，不能清零其他会话或新运行的状态。同一会话同一时刻只跑一轮，不同会话可各跑一轮（A 运行时在 B 发送会立即启动 B，而不是排队等 A）。停止发出取消后保留运行身份并显示正在停止，待网络和子进程真正收尾后才允许再次发送；被取消任务仍按自己的消息收尾。确认卡、提问卡、实时轨迹与实时 Token 快照同样按会话归属：切换到 B 只展示 B 的状态，A 的轨迹继续写入 A 而不覆盖 B 的面板；退出移交按运行登记，A 收尾不会把仍在运行的 B 一并除名。

输入区在当前轮尚未结束或队列有积压时提供「立即发送」，Enter 和原发送箭头沿用「完成后发送」。当前轮包括工具执行、确认/提问挂起及最终保存；等待确认或作答时队列显示相应原因，不显示可用的手动续发。每条普通队列消息也提供「立即发送」，选中条目先发，其余条目保持原顺序。立即发送轮正常完成后，如果同一会话还有流式进度正在保存，最后一笔写入结束时会重新检查该会话的队列并续发。

待发送队列（`ChatSendQueue`）由固定空间的聊天模型按会话持有，入队、预留和出队均绑定明确的会话身份，不能在异步收尾时读取当前活跃会话。立即发送使用独立槽位，保存文本、附件、记忆排除选择及所等待的运行身份；普通队列满员不阻止立即发送。接受请求后先撤销旧轮授权并取消执行，保留旧轮正文、轨迹和用量，等网络/工具退出且结果保存成功才释放待发消息。同一会话仍只有一轮执行。挂起轮直接取消并保存，不通过批准或作答恢复旧工具；重启后没有执行宿主的挂起卡继续沿原人工核对入口结束。后台接管期间仍禁止发送。

正常完成、取消与失败共用身份核验后的派发收尾：显式立即发送优先于普通队列及目标自动续跑，普通停止和失败保留并暂停原队列。结果保存失败时不启动下一轮，立即发送消息保留在卡片中，保存重试成功后续发；普通队列的发送预留失败时回退，不能丢消息。清空或移除立即发送条目会撤销其待发意图，旧轮的迟到收尾不得重新派发。自动续发在成功保存后立即触发，不被标题或记忆提炼请求拖延，切换到其他会话也不冻结来源会话的队列。消息加载、损坏、存储失败和运行门禁都按目标会话判断，其他会话的运行与挂起不影响本会话。队列及立即发送槽位均为内存态，切换会话保留，进程重启不恢复；空间恢复后清除旧队列。

`ChatImmediateSendTests` 使用隔离空间库、受控执行/保存延迟和本地 Provider 协议桩，验证中断收尾、指定条目优先、会话切换、队满草稿保护、普通停止冻结、保存失败重试、批准/提问撤销及目标暂停；不调用真实模型或执行真实写工具。设置 `AGROOM_CHAT_SEND_SNAPSHOT_DIR` 为已有临时目录可输出三语、窄宽和深浅色的队列卡片截图。

历史编辑和重试保留原路径或明确创建分支，不能无提示截断后续成果。错误发生时保留已经流出的正文，并追加可操作的失败状态。提供方只返回残缺工具调用标记时，聊天气泡保留已流出正文并显示 `unparsedToolCall` 的失败提示，不把它渲染成成功的最终回答。

技能页提供技能启用开关、导入、编辑、导出和管理；AI 创建入口跳转到当前空间的新对话。

## 智体模型与对话媒体

智体编辑页提供继承当前对话或独立提供商的选择，可使用提供商默认模型、选择已配置模型或输入端点支持的模型标识。失效配置保留显示和修复提示；人设生成及技能挂载固定到进入页面时的空间。界面说明智体仍为受主调度器委派的专长执行者。

图片附件提供缩略图、点击预览及缩放；视频和音频附件使用原生 `AVPlayerView`，用户点击才加载播放。视频可展开到可拖动边缘调整大小的预览，图片预览同时具有可伸缩内容约束与窗口样式。关闭视频预览暂停；消息离开、切换空间或页面移除时取消加载、释放播放器，迟到加载不得复活播放。文件丢失或系统不支持的编码展示重试提示。界面可播放媒体不表示模型已解析其音视频内容。

回答中的独立 Markdown 链接或媒体引用（如 `[视频](clip.mp4)`、`![音频](voice.m4a)`）使用同一播放器；代码块和普通行内链接保持原语义。媒体文件解析绑定当前会话主目录与显式引用目录，排除另一空间目录、穿越及链接越界；本地图片沿用相同会话范围。远程媒体只在点击播放后通过无 Cookie、无凭据的临时会话下载，校验 HTTPS／回环地址与每次重定向，限制时间及字节，再播放私有临时副本；文档释放时清理副本。

## 结构化提问

`QuestionFormCard` 完整显示问题与长选项，正文和选项遵循阅读字号；短选项在宽度足够时横排，否则纵向换行，长选项直接使用完整行。表单主体按对话可用高度滚动，取消/提交固定可见。宿主保留合理长度内的完整选项，超限拒绝并要求模型缩短，不静默截断选项含义。

## 编码任务审阅

「项目说明与资料 → MCP 工具」在统一对话中可查看，区分本轮/最近一轮实际工具快照与下轮配置，逐项解释未选择、服务停用、只读模式阻止、未加载或配置已变更，并可进入当前空间 MCP 设置。从其他工作区菜单打开时仅预览空间配置，不借用当前对话的运行快照。切换对话时重建工具页签状态；配置修改不向正在运行的一轮追加工具。原「任务变更」不再作为输入区常驻入口，内部编码任务记账、恢复点与检查状态继续保留。见 [15-编程工作流](15-编程工作流.md)。

## 设置页

设置采用左侧固定分类列表与右侧内容表单，按「通用、模型服务、对话与助手、知识与记忆、工具与自动化、权限与安全、数据与备份」组织。分类名不随调度 Agent 昵称变化；同一时刻只挂载当前分类的表单，不使用 `TabView` 同时承载多个 grouped Form，避免 AppKit 布局环。

- 通用：外观、界面语言、日期格式、登录启动、通知偏好和关于。
- 模型服务：有配置时先展示已配置服务，快速接入折叠；无配置时直接展示快速接入。新增与编辑提供者时可填写最多 20 个完整字符的可选别名，普通对话、编码对话及首次任务的模型选择共用别名优先的显示规则；保存后刷新显示，留空沿用原名称与模型。列表右侧的上移、下移箭头调整全局模型顺序并自动保存，对话模型菜单同步刷新；首尾边界禁用对应方向，保存期间禁止重复移动，失败保留原顺序并提示重试。新模型追加末尾，编辑、启用和停用不重置位置。
- 模型列表、余额、连接测试及配置保存的失败反馈按鉴权、限流、余额、服务端、网络和配置类别映射为三语原因与下一步操作；未知服务错误只显示本地化回退文案，不把提供方原始响应、路径或密钥放到主提示。
- 对话与助手：先展示昵称、人设和回复语言，再展示当前空间的技能/智体启用摘要、常用问句与对话显示偏好。模型参数统一位于「模型服务」。完整的技能启用管理在技能页，智体启用在智体编辑页。昵称既用于界面展示，也作为模型自报名注入系统提示词角色定义段（留空或纯空白则不注入，模型沿用默认「调度 Agent」自称）；人设风格由 `[Persona]` 段独立注入，两者互不影响。定时任务与团队重试的提示词走同一身份子句。
- 知识与记忆：先展示检索就绪状态与缺模型时的处理入口，再展示自动记忆和当前空间索引；模型信息、路径与推理测试集中在高级配置中。
- 工具与自动化：Python 环境作为独立子页打开；多智体协作和定时任务分别成组。
- 权限与安全：新会话默认权限、当前空间的脚本授权规则/审批记录与 macOS 系统权限分别展示；保留扩展访问的风险确认，返回应用时刷新系统授权状态。
- 数据与备份：展示空间内统计、全局自动备份策略、当前空间的手动导出/恢复、恢复点与隐私说明。手动导出可明确纳入已登记的外部项目；恢复预览逐类列出覆盖、遗漏及替换，确认绑定已预检包的指纹。恢复点回退逐次确认，后续编辑受到保护。

本机使用效果显示首次有效成果耗时、对话执行、同一统计范围内的成果后续使用、人工确认/作答和完整核对后的恢复结果。提交事件后自动刷新，读取失败保留明确错误，不填零；关闭、切空间和过期读取不回写新界面。清除使用系统确认框，取消保留原统计；确认后清除事件并在同一事务内保存新的统计起点，业务内容保留，旧执行的后续保存不补回计数。系统确认框的点击在独立签名应用中验证，原生挂载回归覆盖提交事件及清除后的实时显示。

作用范围按设置项说明，不能将整个分类视为同一范围：模型服务、助手偏好、自动记忆开关、知识模型路径和自动化总开关为全局设置；技能/智体、记忆内容、知识索引、脚本授权规则与手动备份绑定当前空间。Python 专用运行时固定在 `~/Documents/AgRoom/python-runtime`，依赖包在 `python/<space>/venv` 中按空间管理；环境页只提供状态、主动下载和包管理，缺失时提示下载，不提供本机解释器选择或系统回退开关。默认权限只影响新会话；生成和调度参数从下一轮对话生效。

## 协作页

侧栏「协作」读取当前空间的 `team_tasks` 快照：左侧按更新时间列出任务，右侧展示任务目标、状态、计划中的子任务、独立验证结论、产物内容、证据、开放问题与错误。开启团队写后，页面顶部还显示审批收件箱。

- 审批收件箱：2 秒轮询 `TeamApprovalCenter`，按当前空间展示待审批 `team_write`；每项显示路径、任务/子任务、完整旧/新内容与过期时间，支持批准/拒绝。侧栏「协作」显示待审批数量红点。
- 文件变更：详情区读取当前空间 `team_writes` 快照，逐条展示路径、旧/新内容与回滚状态；支持单文件回滚与「全部回滚」。批量回滚先预检全部文件，任一文件在团队写后被修改则整批拒绝；应用阶段若部分失败，提示仍需恢复的数量并保留逐项记录，不盲目重放。
- 任务快照展示：支持手动刷新、删除和仅限只读交付的重试；新重试使用新的运行身份，不重放文件写入。重启后无运行宿主的非终态任务标记为中断，仍不提供运行中接管恢复。
- 加载、重试、回滚失败按三语原因与下一步操作呈现；文件变化、来源丢失和部分回滚不得直接展示含私有路径的底层异常说明。
- 数据绑定当前空间：`TeamTaskStore` 由 `Hub.makeTeamTaskStore` 现取现建，空间切换时随 `RootView` 的 `.id(space)` 重建，不使用可变当前空间重建旧任务依赖。
- 列表搜索只过滤目标与本地化状态文本；不做跨任务全文检索。
- 执行进度：任务未终态时每 2 秒读取 `TeamProgressCenter`，按子任务显示智体与最近工具；任务终态后协调器清理，页面不再展示。主对话仍只看最终 digest。
- 任务头部同时显示计划估算 Token 与实际 Token；估算来自子任务 `estimatedTokens`，不是精确计费。

## 定时页

侧栏「定时」读取当前空间的 `scheduled_tasks` 与 `scheduled_runs`：左侧任务列表，右侧触发规则、下次/上次运行、指令、能力档、手动运行与运行记录。P0a 只支持只读 Agent 任务，页面不提供写入或团队任务入口。

- 新建/编辑走 sheet：名称、指令、一次/每天/每周/间隔、固定时区、启停与通知策略；保存前校验名称、指令、时间、星期和间隔，一次性任务启用时必须选择未来时间。时区在创建时固定并展示，不随后续系统时区变化漂移。
- 启用/停用、运行一次、停止和删除都有确认或明确错误反馈；删除任务保留历史运行记录（页面不再显示），并先取消当前运行。运行中切换编辑只影响下一次，正在运行的定义使用启动时快照。
- 运行记录按时间列出状态、触发方式、用量与输出；运行中显示进度，停止是异步请求，真正收尾后才解除。
- 总开关（设置 → 工具与自动化）关闭时页面顶部显示设置入口；任务仍可查看/编辑，但不会扫描或手动运行，不伪造执行状态。
- 数据绑定当前空间：`Hub.makeScheduledTaskStore` / `makeScheduledRunStore` 现取现建，空间切换时随 `RootView` 的 `.id(space)` 重建。`ScheduledTaskCenter` 是 App 级进程内调度器，会扫描两个空间的到期任务，但页面只展示当前空间；非当前空间的通知不带任务名，只发通用结果。
- 执行复用 `ScheduledRunner` / `EngineAssembly` 的只读白名单；文件读取走 `ScheduledFileReadScope`，并受装配时绑定工作区的主目录与引用文件夹限制，不读取其他工作区或另一空间目录。无人值守时遇到确认或提问失败关闭。限制为 App 运行时执行、最多 12 步、4096 输出 token、180 秒；没有后台 helper、对话工具或任务级自定义预算。
- 完整契约、数据表、错过/重叠语义和后续阶段见 [14-定时任务设计](14-定时任务设计.md)。

## 文件页

文件页根为受管区（`~/Documents/AgRoom`），一级节点是受管根（files / default-chat / workspace / privatespace）；受管区之外的登记工作区目录作为受保护节点挂到树上，否则这些目录不可达。读操作走 `FileAreaService`（受管根校验 + 隐藏标志），写操作由用户主权直接触发。

- 文件页服务必须注入登记工作区的追加根，否则受管区之外的目录无法列举。
- 当前文件夹或树节点读取失败时展示带重试入口的提示，不把失败伪装为「此文件夹为空」；操作失败按权限、来源丢失、名称冲突、数据库忙等类别显示三语原因及恢复动作，不直接显示含绝对路径的底层错误。
- 在文件页删除或重命名工作区目录时必须同步工作区注册表（移出登记 / 跟随新路径）；删除确认文案需说明该目录是对话工作区。
- 受管根本身不可删除或改名。

## 邮箱页

列表多选、按状态与数量呈现的右键菜单、跨文件夹/账号的本机正文筛选与保存筛选、原件查看、批量回执、废纸篓、回复全部、附件保存/撰写/转发、本地归档选择导入/撤销与 EML/PDF/MBOX 导出的统一契约见 [17-邮箱工作流](17-邮箱工作流.md)。

邮件列表顶部将筛选与常用筛选放在一起：筛选按钮显示附加条件数量，常用筛选使用书签图标，窄栏时收为图标并保留悬停与辅助功能名称。下载、自动同步和列表显示使用次级图标，选择操作放在范围说明行。筛选浮层按范围、状态、地址与附件、大小和日期排列，条件即时生效；日期输入保留固定位置，正文说明独占整行，底部常驻清除与完成。清除只重置附加条件，保留搜索词和当前范围。

邮件右键与选择菜单将高频动作分组，单封的复制、发件人筛选、AI 回复和原文查看收在更多；搜索来源定位按场景保留在首层。同一不可用原因合并到可在忙碌时打开的说明子菜单；多选数量与冻结目标保持一致，原有删除确认与批量处理不变。附件复制文件名不触发读取，在线/离线准备说明按实际邮件来源呈现；导出弹窗的 Escape 复用既有取消与关闭。

导出窗口支持 EML/PDF 命名、按账号目录或月份分组、目录名称及全量路径的搜索与分页预览；MBOX 展示各组首卷并说明卷数在写入时确定。窗口分别呈现本机可准备、缺失、不可补全和大小未知的范围，离线来源不显示下载开关。布局计算和路径检索在后台取消旧版本；保存位置选择前冻结本次选项，来源变化要求重新预览，关闭后不能由迟到回调重新提交。实际路径、相对结果清单及保留原件恢复规则见邮箱专项页。

侧栏隐藏只控制当前空间目录树与收藏的呈现，保留当前阅读，提供显示隐藏项的入口。移动选择器固定原邮件集合与账号，支持完整路径检索、最近/收藏与隐藏目标；关闭、离开页面及空间切换取消在途复核，提交后复用原批量回执。文件夹可见性在目录或偏好更新时计算，避免每行重建整个父子关系。菜单与详情按实际目标显示不可用原因；具体身份复核与副作用边界见邮箱专项页。

文件夹侧栏底部的「本地缓存」以弱化的单行入口显示当前文件夹的覆盖数量，同步中显示进度指示；点击后在浮层查看日期范围与上次核对的完整度，尚未核对时明确标记未知。浮层提供「加载更早邮件」和经确认的「重建本地缓存」，并说明邮件列表覆盖不代表正文和附件已全部下载。更换文件夹后关闭旧浮层与确认状态。这些操作复用账号租约、取消与错误呈现；切空间或取消后的迟到收尾通过同步操作身份失效，不能清理新操作的状态。加载与搜索仅反映本地资料，不因没有结果而暗示远端不存在。

邮箱页是三栏布局：邮箱（账号）列表 / 邮件列表 / 邮件详情，实现于 `Features/Mail`。

- 前两栏宽度由用户拖动，并在拖动结束时经 `SplitColumnWidth.persist` 记忆到 `UserDefaults`（窗口缩放 / 自动挤压不写回）；布局偏好不含隐私，因此不按空间隔离。
- 邮箱侧栏的账号名与文件夹名使用 15pt 字体，图标与行距同步放大，长文件夹名保持单行并可悬停查看全名。平铺与树形共用排序：每层按「收件箱 / 草稿 / 已发送 / 归档 / 垃圾邮件 / 垃圾箱 / 其它文件夹」排列，同类按名称自然排序；保留服务器父子层级，父节点缺失的文件夹提升到顶层显示。
- 当前账号的收藏文件夹另列在侧栏顶部，保留原目录树。移动菜单优先显示实际目标账号的最近成功目标与收藏；批量移动在归属刷新完成后才重新启用，避免继续按旧位置构造菜单。保存筛选支持仅改名或明确替换当前条件与范围，编辑时核对原记录版本。
- 统一收件箱独立于当前账号目录，只查询当前空间内本机收件箱角色邮件，结果显示实际来源。刷新逐个处理已启用在线账号的收件箱，失败继续其余账号并列明名称；本地归档不连接网络。该范围可保存筛选、导出匹配结果，点击原账号或文件夹返回单文件夹范围。
- 导入预览可只读查看原件正文和附件元信息；重复项可查看同批候选或重新核验后的归档原件，返回时保留勾选。结果可按状态筛选并打开对应邮件或本批范围；批次查询只包含实际新增且仍保留的邮件，支持分页、保存筛选与全部匹配项导出，点击账号或文件夹退出。旧回执缺少关联、原件变更或邮件已移除时说明原因，不猜测来源。
- 导入窗口提供 MBOX 格式选项；自动模式遇到 Content-Length 引用歧义时展开选择，切换后重新读取来源并清除旧勾选，忙碌时固定格式。预览和结果显示实际变体，旧式格式的不可逆引用限制在选择时说明。主体滚动而底部操作固定，Escape 取消或关闭；关闭撤销临时来源与在途回调，不触发迟到导入或导航。
- 详情可切换会话阅读，按同账号的精确线程头展示本机已知往来并分页；当前选择独立保留，不改变续页游标。展开卡片才读取正文，折叠或离开取消正文、附件及内嵌图片任务；会话模式不同时读取单封正文。卡片标明真实来源并复用详情和操作确认，快捷操作绑定有焦点边框的卡片，回到列表或单封模式恢复列表对象。
- 列表只读本地已同步的摘要，选中详情时再取正文与附件；未同步的邮件不会凭空出现，空态提示用户先同步。
- HTML 正文使用非持久化 WebView；只允许应用发起的初始文档加载，不在邮件视图内导航。用户主动点击的 HTTP(S) 链接交给系统浏览器，自动跳转、子框架和其他协议均拦截。外部图片与跟踪像素不加载；支持的 CID 位图只从当前邮件、当前空间的附件读取，按图片预算验证并提供失败数量及重试。CID 响应禁止缓存，切换来源时重载，避免相同 CID 复用上一封图片；页面离开及 WebKit 请求停止时取消读取。完整边界见 [17-邮箱工作流](17-邮箱工作流.md)。正文在深浅色界面中都作为有外侧留白、圆角细边界的浅色阅读纸张展示；WebView 默认底色为白色，未指定颜色的文字使用深色备用值，邮件自身的背景与文字 CSS 继续生效，不做全局反色。
- 邮件列表标题和详情元信息使用共享字体角色响应“较大界面文字”。详情操作行在宽栏显示图标和文字，空间不足时切为单行图标；各操作保留悬停提示、辅助功能名称和足够的点击区域，隐私徽标也在窄栏收为图标。
- 服务器诊断保留操作阶段、状态与脱敏说明；`BAD` 命令级协议错误提示保留错误信息并反馈，不套用文件夹不存在的操作建议。
- 账号配置走 sheet；撰写（新写 / 回复 / 转发 / 重开草稿）走**原生独立窗口**，由 `MailComposeWindowCoordinator` 按 `(space, draftID)` 注册：同一草稿只激活一个窗口，不同草稿可同时编辑。
- 撰写窗口在顶部提供发送、保存、附件和收件人检查。信头按收件方式显示地址标签，正文上方可设置文字格式、插入签名或回复模板。引用默认折叠，低高度窗口可滚动。底栏显示保存状态及服务器草稿操作。AI 侧栏宽度随窗口调整，要求、选项和候选可滚动，应用操作固定在底部。
- 撰写窗口的状态（收件人 / 正文 / 原文引用 / 自动保存 / AI / 发送）由 `@MainActor MailComposeViewModel` 持有，`MailComposeView` 只做绑定。因此最大化、系统全屏、折叠 AI 面板、语言重建都不会重新初始化草稿。
- 窗口在创建时固定其空间与账号；主窗口切换空间、切换账号或改选其他邮件都不改变已打开窗口的发件人与原邮件上下文。空间内服务始终由窗口模型按固定空间从 `Hub` 现取现建，不进入 `Hub` 缓存。
- 「最大化」铺满当前屏幕可用区域（保留菜单栏与 Dock），再次触发还原；换屏或退出全屏后窗口回到可见范围。默认尺寸约 `900 × 700`，最小约 `640 × 480`，不再有固定宽高约束。
- 应用退出时逐窗保存邮件草稿；任一保存失败即取消退出、保留撰写窗口。Markdown、邮件与原生小应用的草稿检查完成后才暂停笔记队列并准备后台交接。单独关闭窗口（红色按钮 / 菜单关闭 / ⌘W）由窗口委托处理：已保存直接关闭，有未保存修改询问「保存并关闭 / 不保存 / 取消」，保存失败保持窗口并展示原因，AI 生成中先取消生成，正在发送可关闭窗口。
- 回复按**固定原邮件本地 ID** 读取正文与 AI 上下文，不再依赖详情页当前加载的正文。正文读取规则：本地已就绪直接读，只有摘要时按需拉取并显示进度，只有 HTML 时提取可读文本，失败给出重试入口（不用摘要冒充原文），过长按上下文预算裁剪并提示读取范围。
- 回复地址与线程头：有效 `Reply-To` 优先于 `From`，`In-Reply-To` 指向被回复邮件，`References` 保留原链并追加被回复邮件 ID（去重并限长）；旧邮件缺字段时回落，不影响正常回复。`Reply-To` 来自 ENVELOPE，`References` 在正文拉取时从头部解析并回填。
- AI 面板（`MailAIPanel` + Core `MailAIService`）提供需求输入、模型选择、语言 / 语气 / 长度、上下文状态、流式候选与「生成 / 停止 / 重新生成 / 替换 / 插入 / 撤销」。AI 结果只作用于回复正文，原文引用保留，发送时再组装。
- 生成身份固定为「草稿 + 生成世代」：新一次生成让旧回调失效；生成期间仍可编辑；网络中断保留片段并标记未完成；「停止」只取消请求，不丢弃用户正文。
- 发送由独立 `MailSendCoordinator` 持有任务与固定空间上下文，窗口关闭后仍按既有策略完成投递并把结果落回原空间，列表经数据变更通知刷新。AI 不能代为发送；正在发送、结果未知或已投递的草稿禁止应用候选与覆盖保存，发送四态语义不变。
- 主窗口与撰写窗口设有明确标识；菜单栏「显示阿吉屋」、全局快捷键、Dock 重开与设置 / 帮助入口统一按标识查找主窗口，避免误选编辑器。
- 移动先远端成功再改本地；普通删除经确认移至废纸篓，废纸篓内永久删除继续复用原安全删除与二次确认。批量只为标记提供直接重试，移动/删除的未知结果提示同步核实。
- 侧栏、账号与文件夹菜单及应用菜单共用文件夹管理窗口。新建、改名及删除先只读展示完整路径与邮件范围，再显式确认；模型固定空间与账号，关闭或换空间取消预览。远端修改保存逐目录回执，未知结果提供独立核对页而非重试按钮；需清理服务器缓存时列明范围并要求当前窗口内勾选同意，本机自产原件保留。详见 [17-邮箱工作流](17-邮箱工作流.md)。
- 邮箱页数据属于当前空间，随空间切换与其他功能页一起重建。

### 选中与刷新的竞态约束

- 详情正文按「选择时分配的请求令牌 + 当前选中 id」双重核对后才写 UI：慢请求返回时若选择已改变，结果直接丢弃（否则 A 的正文会显示在 B 的标题下，属于内容错配）。
- 文件夹与列表刷新按自增世代号丢弃过期结果；`selectFolder → reloadFolders → reloadMessages` 的级联刷新只在世代号未变时继续。
- 同步是可取消的长任务：界面显示「已完成/总数」的逐文件夹进度并提供取消入口；取消发生在批次之间，已写入的批次保留、游标可续传，因此取消不算失败。
- 发信结果分四态：`sent` / `failed` / `resultUnknown` / `deliveredLocalSaveFailed`。最后一态表示**邮件已经发出**，只是本地副本落库失败——界面必须提示「已发送（本地记录失败）」并禁止在原文上重发，同时展示「已投递但未归档」的草稿残留供用户核实后清理。
- 搜索结果只在输入停顿后才提交（防抖 250ms），避免每敲一个字符都扫描全部历史正文。

## 引擎组装

每轮发送从当前空间读取 Provider、智体、技能、知识、记忆和邮箱，通过 `EngineAssembly` 与 UI 注入的浏览器工具构建引擎。不要在单个 Feature 内复制另一套工具注册或安全策略。

发送前涉及图片和文件的磁盘读取应离开主 actor。模型请求的附件提示必须反映实际成功加载的附件；超限或失败项要在 UI 中明确显示。

## MCP 设置

「设置 → 工具与自动化 → 管理 MCP 服务」打开绑定当前空间的管理窗口，可添加/编辑/移除远程服务、粘贴 HTTP / JSON 连接配置、填写独立 Token、测试连接并选择工具。多个导入服务需先选择目标，粘贴不自动连接或保存凭据。工具列表及「项目说明与资料」的 MCP 工具页签支持搜索与只看已选项。测试只发现目录，不调用业务工具；刷新后仅保留定义未变化的选择。描述来自外部服务，不能据此授予只读或免确认资格。

新增或编辑模式与配置快照由同一个弹窗状态携带，标题、Token 提示和保存操作共用这一模式；新增服务按创建保存，已有服务仍校验配置修订号。连接测试结果与保存错误分别展示；保存冲突明确说明修改未保存，并引导关闭编辑窗口、重新打开服务后重试。关闭编辑窗口会刷新服务列表，避免再次打开时沿用旧配置。

切换空间关闭原设置窗口，所有异步探测与保存仍使用创建时固定的服务。修改端点、认证或 Token 会取消旧探测、清空旧目录与选择，并用请求身份丢弃迟到结果。凭据保存失败、配置冲突与无效目录通过三语原因及下一步操作展示，不显示原始网络/数据库诊断或 Token。

前台主对话显式挂载已选择的工具。会话权限选择「自动审核」后，查询候选由无工具审核模型核对；未启用、不确定或审核失败时使用普通确认卡。写入、删除、发送与未知操作仍使用逐次硬确认卡。卡片展示真实服务、端点、工具和参数，仅允许本次批准，不展示本地文件或子进程的沙箱保证。项目中的 MCP 工具页签说明查询审核与人工确认的区别。支持文本/JSON 结果，其他内容明确省略。后台、定时和智体尚不挂载 MCP；提供 MCP 工具的对话暂不支持退出后续跑。完整边界见 [03-工具系统](03-工具系统.md#外部-mcp)。

## 流式渲染

聊天图片气泡先以固定尺寸占位，后台按显示像素降采样。缓存按空间、文件身份和版本区分，以解码后的字节数计成本。可见文件被替换时重新读取，气泡离开后取消等待。Markdown 按最近一次解析耗时合并中间更新，终态立即提交完整原文。Instruments 的 Points of Interest 分别记录解析、TextKit 内容更新、排版和文档首帧绘制。

聊天、技能、Markdown 编辑器与知识预览共用 `MarkdownView`。后台 worker 用标准解析器处理完整累计快照，保留跨增量的代码围栏、列表和后到的引用定义。同一消息连续追加时，一个解析任务可以先显示已完成的前缀，等待区只保留最新原文。替换原文、切换文档或空间、退出视图都会取消旧流。在含公式的文档里，遇到缺少源码位置的换行，解析器用前后节点的 UTF-8 位置判断它是否落在公式内。

消息列表共用会话的来源上下文。空间、会话、已授权工作区及引用目录、数据策略变化时重新构造。注册表按空间通知目录和授权变更，其他窗口撤销引用目录后，已打开的聊天也会刷新。绘制消息行只读当前空间的快照。实际读图仍校验来源、路径和空间边界。

解析树、按块富文本和资源均由文档视图持有。字号变化复用解析树。新资源加入时，仍在预览中使用的图片、公式或图表可以完成当前任务，移除资源及切换上下文会取消旧任务。资源结果应用到最新文档。同一批次中相同后端与外观的离线渲染复用非持久化 WebView，每次清空输出，批次结束、失败或取消后释放宿主。

共享渲染已支持嵌套列表 / 引用、任务标记、删除线、标准换行、代码围栏与语言、GFM 表格对齐和横向滚动、文档级引用式链接。复制使用与「参考」相同样式的普通按钮，输出当前回答版本的消息原文，不显示下拉菜单。技能 frontmatter 只在完整闭合时剥离，并保留原文件源码范围。图片已接入文档私有的本地 / HTTPS 加载器，来源上下文固定到空间与文档目录，校验路径、重定向、响应长度和解码像素；行内图片和公式使用原生附件，独立图片和公式保持原始比例；Mermaid 占满当前对话内容宽度，高度随比例计算。图表上方提供明显的放大入口，预览默认适应宽度，并支持适应窗口、实际比例、缩放及拖动查看；图表以有界 PDF 矢量表示绘制，保留位图回退。KaTeX 与 Mermaid 随 UI 资源离线打包，在独立非持久化 WebKit 中渲染，资源到达后创建新富文本以同步失效高度；快照按实际位图像素限制分辨率，避免 Retina 重复缩放；失败保留 alt 或源码并显示语法 / 格式、超时或资源超限原因，可重新加载。公式保护 LaTeX 原文，Mermaid 仅在围栏闭合后启用。脚注和提示块仍无专用后端；具体规则见 [Markdown 渲染增强设计](../design/2026-markdown-rendering-design.md)。

被截断的正文由引擎在尾部追加可见提示（本地化），UI 只需按普通正文渲染，不要另外拼错误状态。

缓存解析应在锁外执行，缓存有明确上限与失效条件。优化时必须回归跨 chunk 的代码块、列表、表格和链接正确性。

### 富文本高度测量与缓存

聊天正文的富文本段由 `SelectableTextView` 渲染。块缓存给出显示版本共有的块数与 UTF-16 长度，TextKit 只在剩余后缀内比较文字和属性。视图跳过中间版本时按实际持有的块重新确定起点。显示和测量栈在相同的完整字素边界更新，连续正文仍可跨段选择。代码块视图身份不包含不断增长的源码，保留滚动与选择状态。高度必须用独立的 `NSLayoutManager` / `NSTextContainer` 按实际宽度 `ensureLayout` 后取 `usedRect.maxY`，并合并结尾换行的额外行片段；不能使用 `NSAttributedString.boundingRect`。引用和列表的制表位可能让 `boundingRect` 只量到首行，得到远小于实际排版的高度，后半段正文随之被裁切。

- 测量栈独立于屏幕上的文本视图，`sizeThatFits` 期间不改动屏幕视图尺寸、不写 SwiftUI 观察状态。
- 高度缓存放在文本视图内部，键为「内容修订号 + 精确宽度」；`setText` 递增修订号并清空缓存；宽度变化只失效固有高度，不恢复 `layout()` 中的无条件 `invalidateIntrinsicContentSize()`。
- `sizeThatFits` 与 `intrinsicContentSize` 共用同一测量路径；屏幕文本视图与测量栈必须使用一致的 `textContainerInset`、`lineFragmentPadding`、字体行距与非连续排版开关。
- 回归覆盖引用/列表混排、流式转终态、长短版本切换、窄宽及临界换行宽度、尾部换行、中英文与 emoji；验收重点是最后一个字符所在行落在给出高度内，而不是固定点数。

## 浏览器

后台标签的右键菜单提供“休眠”。确认前会说明表单和页面历史将丢失。活动标签、正在加载、正在执行工具或等待表单确认的标签不能休眠。休眠会撤销该页的交互快照并释放 WebView。恢复时在原空间沿用网站数据存储，新建 WebView 并重新打开可安全重载的 GET 地址。

减审不等于免审：除 ARIA 搜索表单和 search 输入外，原生 GET 表单可凭“精确查询按钮标签＋可用且非只读的具名查询文本字段＋受限控件类型”进入查询候选；禁用提交按钮不成为查询候选，字段可用性包含 fieldset 继承禁用状态。传统查询候选同时检查按钮与所属表单的祖先动作标记，按钮通过 form 属性在表单外关联时也不能漏检。POST、提交覆盖属性、内联动作、敏感字段和危险目标不因按钮写着查询而放行。候选仍经过原有模型审核或本任务授权，业务填写和任意 JavaScript 保持原审批边界。

页面读取额外展示同表单分组、精确字段名、禁用／只读状态与选项可用性，帮助模型把同表单改动合成一份填写计划，避免为检查就绪状态调用任意脚本。普通读取的选项摘要有界，聚焦元素读取提供更大上限，仍超限会明确标记截断；敏感值继续遮蔽。审批回退区分 HTTPS 要求、证据截断和证据过大，三语显示原因，不通过放开 HTTP 自动审核来减少弹窗。

标签复用按完整 URL 判断，激活同页不重载表单。弹窗使用 WebKit 提供的配置创建真实子视图，不复制来源表单、不伪造 opener、不注入阻塞事件循环的同步对话框模拟。旧站点依赖同步 showModalDialog 的流程仍需专项适配，UA 切换不代表完整 IE 兼容。

读取和滚动摘要遮蔽敏感输入值，并将页面标记为不可信参考数据。普通顶层链接通过原生导航打开；结构化菜单/页签及同源 GET 搜索表单由宿主作为候选分别进入任务授权和模型审核，不以页面文字证明只读。任务范围与单次页面执行身份独立，同源跳转或重读后可继续；跨来源、关闭标签和 WebContent 终止撤销相关任务授权。业务提交、危险目标、脚本及未知动作保留单次硬确认。

填表展示完整顺序计划，支持等待联动选项及在已观察表单内按精确名称定位后续字段；一份计划只消费一次，输入可能触发远端保存，提交另行审批。执行前校验整批已知字段，执行中逐步检查目的地、字段类型、敏感性及实际状态；失败和取消不会重放已完成步骤。DOM 装饰性变化不再按整个表单 HTML 误判业务操作变化。专用确认卡使用结构化事实展示站点、页面、操作对象、字段和值、授权类别及审核转人工原因，三语格式化只在 UI actor 执行。点击回执仅证明派发，最终结果必须再读页面核验；等待失败明确结果不确定，不能自动重放。

标签软预算仅回收空白页，保护已加载页面和执行中工具，不能为了限制数量丢弃未保存表单；空闲休眠与内存硬上限仍待实现。元素编号使用弱引用观察和事件触发，不持续轮询后台页面。截图按空间写入临时目录，当前仍返回路径，多模态结果与自动清理仍待实现。浏览器两处界面订阅标签状态，刷新标题和导航按钮，并提供跟随 AI 开关；关闭后工具活动不自动切换当前页或弹出面板。内部编号与元素快照运行在隔离脚本环境；DOM 仍与页面共享，页面文本始终是不可信数据。


`BrowserService` 管理 WKWebView 标签和共享登录会话，并实现页面读取、点击、填表、截图、滚动和 JavaScript 桥接。浏览器工具位于 UI 模块，通过 `DispatcherTool` 注入 Core。

「保存网页到知识」在触发时固定空间、标签和 URL；异步提取标题与正文后再次核对三者及取消状态，提取期间切换空间或标签就放弃写入。知识服务必须按发起空间现取现建，不从写回时可变的当前空间取服务；若写入已开始，结果仍只归发起空间。

每个标签会持有较重的 WebContent 资源。标签管理应提供软上限、批量关闭或空闲休眠，同时保护正在执行的工具和未保存表单。

## 本地化和样式

- 用户可见字符串通过 `L.string` 获取，并同步维护 en、zh-Hans、zh-Hant。单键缺失先回退英文，英文仍缺失才返回键名；回退不能代替补齐三语资源。SPM 构建使用生成的 `Bundle.module` 定位资源，不能假设测试运行器主 Bundle 位于应用旁；Xcode framework 使用自身资源 Bundle。
- 面向模型的系统提示和工具描述按协议语言维护，不通过 UI 本地化资源拼接。
- 使用 `MeetStyle` 的 `MeetTypography`、`MeetSpacing`、`MeetRadius` 与 `MeetLayout`，统一列表标题、辅助信息、控件、卡片与列标题栏，避免 Feature 自建平行设计常量。
- 阅读字号为全局外观偏好，支持 14–30pt、默认 15pt。通用设置与工具栏阅读入口提供步进、预设、实时预览和恢复默认；「阅读」菜单使用 ⌘⌥+ / ⌘⌥− / ⌘⌥0，保留浏览器和图表自身的缩放快捷键。正文、输入框、Markdown 标题/表格/代码、审批摘要和定时报告共同遵循阅读字号；HTML 邮件通过页面缩放覆盖内联固定字号，不因字号变化重新加载。
- `ReadingTypography` 值对象参与文档私有渲染缓存键。只改字号时复用同一文档的解析树与已加载资源，新排版就绪前继续显示旧富文本，不回退成原始 Markdown。历史阅读记录当前消息中的相对位置，在既有延后滚动收尾路径中重排定位；用户滚动、搜索或切换会话立即接管。
- 界面文字另有「标准 / 较大」偏好，通过只含外观状态的主 actor 对象更新共享字体角色，覆盖导航、列表标题和辅助标签，不重建空间页面。
- 聊天正文随对话栏可用宽度排版，保留用户靠右、助手靠左的气泡布局、助手浅灰底色及原有消息、段落与操作栏间距；阅读字号设置只调整字体大小。固定右栏在正文满足最低可用宽度时生效，窄窗口沿用临时浮层降级，不扩大窗口最小宽度。
- 技能与智体列表为行内操作保留固定热区，常态保留弱化图标，悬停或选中时提亮，不通过插入/移除按钮挤动标题；重要摘要使用次要文字色。
- 辅助功能标签、键盘操作、错误状态和进度反馈与视觉改动一起考虑。

## 跨层页面跳转与帮助页

菜单栏与应用菜单的「设置」「帮助」集成在主窗口导航中：`AppNavigation` 是 App 层驱动主窗口切页的唯一入口，页面寻址统一用 `HubNavItem.rawValue`。跳转先定位主窗口（按标识查找，见邮箱页约束），再投递路由；主窗口尚未挂载时路由先挂起，`RootView` 挂载后用当前空间补发，避免关闭窗口后点菜单无反应。挂起路由在接收方消费后清除，不会在重新挂载时重复切页。

`RootView` 消费路由与页内跳转共用同一条路径（空间校验 → 页名解析 → 切页），因此「设置」「帮助」与页面内互相跳转的语义一致。

应用菜单「前往」与主侧栏共用导航分组；文件菜单提供新对话，搜索、任务中心和成果库有固定快捷键，显示菜单提供侧栏开关。状态项提供同源的新对话、搜索、任务中心及成果库。动作携带发起空间，主窗口未挂载时保留一次，挂载后补发，空间不匹配时丢弃；新对话先保存独立草稿并保护原输入与附件，保留所选工作区。对话菜单的查找、导出和停止只在聊天焦点上下文可用，调用既有操作；全局快捷键不再由隐藏按钮重复注册。

聊天输入框的单行 `/` 前缀查询展示上述四项已有应用操作，复用菜单名称和空间路由；上下键选择、回车打开、Esc 关闭，也可用鼠标或 VoiceOver 操作。只在选择操作时移除斜杠查询并保存草稿，附件和其他会话草稿保留；正文中包含 `/` 或多行输入照常作为普通消息。该入口不发送模型请求，也不新增工具或权限。

帮助页（侧栏独立入口，应用菜单「帮助」同源）沿用设置页的左侧分类、右侧单一表单布局，分类为快速开始、功能导览、快捷键、隐私与数据、常见问题；侧栏宽度、选中样式与标题层级保持一致，每次只挂载当前分类。功能导览按主侧栏的常用、资料、能力、系统分组，点击沿既有路由打开功能页，顶部保留打开设置入口。内容只描述已实现能力，全部走三语本地化；新增功能页时同步补齐 `help.tour.<page>` 文案，否则该页在导览里显示键名。

## 修改检查

UI 改动至少检查：两个空间切换、会话切换、运行中停止、停止后立即发送、错误和取消、窗口重开、三种语言、键盘操作，以及长文本和多标签下的内存与主线程工作量。

## 知识库浏览

知识页左栏使用统一树展示知识库、多级文件夹与条目，文档与 Wiki 均为叶子；「全部知识」「未分类」是当前空间的虚拟入口。目录默认聚合全部子目录条目，可切换「仅本层」语义；树中点击条目在右侧阅读，顶部可点击路径和返回列表入口负责导航。右侧列表将选择与阅读分开：单击选中，⌘/⇧ 多选，双击或 Return 阅读；选择数量与批量「移动到」入口常驻列表标题栏，切换目录或筛选清理选择。展开、选中与包含子目录偏好按空间分别保存，页面的异步读取、搜索、导入和生成始终固定发起空间。

树中右键支持新建子目录、重命名、移动、同类兄弟节点上移/下移及删除。文件夹或条目可拖入同空间的目录与知识库，条目支持多选拖拽；只有条目可拖入未分类；拒绝来自另一空间的拖拽载荷。删除确认说明受影响的子目录和条目数，并区分保留内容与删除全部。保存或移动失败时保留表单及输入，错误给出可执行的恢复动作。

知识页的 AI 草稿、浏览与导入失败显示三语领域文案；未知错误只保留本地化恢复提示，不把源文件路径、服务响应或知识正文放入主提示。需要诊断时只记录脱敏的错误类型和码。

导航文字使用共享的 15pt 字体，知识库名称加粗；条目列表标题为共享 14pt，路径、摘要、时间和图谱标签为 12pt，工具栏为 13pt，「较大」界面文字在这些基础角色上同比放大。正文阅读与 Markdown 编辑器遵循全局阅读字号；长名称单行截断并可悬停查看完整名称。树按摘要构建，正文按需加载；迟到详情和检索结果通过请求身份及取消检查丢弃。初始加载失败展示重试入口，取消也必须结束加载态。读取健康空间连接不发布无变化的故障状态，避免服务装配反复触发根导航更新。

恢复导航偏好必须只读。`@Observable` 属性经宏展开后使用访问器，即使在初始化器中赋值也可能执行 `didSet`；模型构造时直接初始化存储字段，不触发导航持久化。否则页面重建会再次写 `UserDefaults`，进而使主窗口持续重建，知识库停留在初始加载态。

图谱按可用区域初始适配并提供恢复适应窗口入口，节点较多时按聚焦显示标签。图谱提供标签、语义相关、实体关系及已排除关系筛选；语义连线使用虚线，实体使用独立颜色。选择节点聚焦关联，关系列表可打开证据、来源文档与核对操作。自动构建页提供本地关联更新及当前空间的模型抽取开关，首次启用说明片段发送与实际用量；失败重试与任务进度沿用任务中心。

文件导入先进入 `KnowledgeImportSheet`，系统选择器确认后逐个提取，显示文件来源、状态、完整正文、页码警告与逐文件操作，再明确保存。新资料和无编辑冲突的来源更新默认保存，重复、未变化和编辑冲突默认跳过，可另存副本；替换已编辑正文还需单独确认。选项改变后须重新提取，失败行可重试；关闭或切换空间取消未完成操作，迟到回调不能继续保存。正文预览使用只读、可选择的原生文本视图，遵循阅读字号并可滚动查看完整内容。

导入记录展示本空间的近期批次和保存、跳过、未完成状态；重新选择不会凭记录中的旧路径取得文件授权，清除记录需确认且不删除知识。条目详情的「来源与提取版本」提供显式检查、重新选择来源更新及近期正文版本阅读。来源丢失、内容变化、需要重新授权和知识已编辑分别提示；更新前并排对比当前正文与新提取正文。原文件由用户管理，已保存版本在来源删除后仍可阅读；恢复的来源必须重新选择。系统选择器和提取服务由 UI 组合点接入，不赋予模型额外目录权限。

## 知识检索设置

设置页「知识与记忆」提供本地语义检索开关、外置 GGUF 模型路径选择/输入、默认路径恢复、在访达显示、推理测试，以及当前空间的索引计数、更新/重建操作。推理程序随 App 内置，权重保留在 App 外；模型缺失和推理失败展示三语恢复提示。索引作业通过统一作业列表展示进度和取消，切换空间后重新绑定该空间的服务。

知识列表搜索在输入停顿后异步执行混合检索，并限定当前知识库、文件夹、包含子目录选项和类型的条目集合；取消和请求身份校验丢弃迟到结果。列表结果显示完整所属路径。聊天检索支持按库或目录指定范围，返回片段来源、目录路径和原文位置；语义索引尚不可用时如实标明关键词模式。

## 任务、成果与参考内容

- 工具栏任务中心由 `ProductTaskCenter` / `ProductTaskDetailView` 展示当前空间的独立对话运行、协作任务、定时运行和后台作业。提供待我处理、进行中、已结束、来源与摘要搜索，按统一游标继续加载；不再用会话最新回答替代所有历史尝试。运行宿主缺失的活动记录显示需检查。
- 每次运行的详情可回看原请求、结果、真实步骤和成果，复制结果、预填新对话或继续处理成果。预填不立即执行，复用当前已登记的工作区并继续遵守既有确认规则；任务详情的成果读取限定到关联工作区及其显式引用。较长内容显示摘录说明，旧回答历史不推算未知耗时或补造统计。
- 复用请求仅保留原任务内部工作流作为续问提示，新请求仍自动判断，追问优先采用来源的已登记工作区。路由预填先保存独立会话，原会话草稿、附件和未归属输入分别保留；保存失败、页面切走或输入已改变时不覆盖现有输入。新草稿不自动发送，不携带原任务的审批。任务用量区分已报告的零值和缺失计数。
- 「打开来源」携带具体回答、协作任务或定时运行的身份。旧回答使用已有完整会话补载器，协调分页请求后定位并突出该消息，不切换已选回答版本；只有展示快照的旧确认恢复为只读核对卡，不代为批准。较早协作任务可按 ID 补读，定时运行可补读最近页之外的记录、展开并滚到结果。记录不存在或不可读时明确提示，任务详情仍保留已保存结果。路由、来源补载和页面服务固定发起空间，旧异步请求不能改写新空间的选择。
- 后台作业需要处置时，列表提供「处理这次运行」。历史未保存的作业可重试保存回执。中断的作业可标为已处理，移入「已结束」并保留中断记录。中断的知识索引可直接打开当前空间的「知识与记忆」设置，通过原有「更新索引」操作继续。工具栏只缓存近期作业，统一中心可翻页查看数据库中的完整历史。
- 每条已停止且可清理的运行都有「移除记录」按钮，包括「待我处理」中的失败运行和已中断的索引作业。确认后只移除任务中心的这一条记录。「批量清理任务记录」覆盖当前空间的所有来源、筛选和分页。进行中的任务、等待确认或答复的任务、等待保存的回执和仍需人工恢复的对话继续提供原有处理入口。清理结果显示实际移除数量，原始报告和成果可从来源页面查看。浏览较早历史时可点「刷新」更新列表。
- 知识导入的预览、确认保存和重试显示为当前空间作业，关闭导入窗口和任务详情中的取消都作用于同一作业。排队取消不读取文件，部分失败显示数量与逐文件错误，历史保存失败不重复已经完成的知识写入。
- 「未完成」与「已完成」分开：引擎正常结束但缺少必需产物时，任务中心按 `incomplete` 展示，消息正文尾部同时显示具体阻塞原因（由 `TaskCompletionAssessment` 的稳定 code 经 `product.completion.*` 三语本地化）；界面不再把「只说准备做」的结束状态呈现为完成。
- 守护进程的「需人工恢复」任务显示未决操作与已记录步骤；查看操作记录时按固定来源重新核对日志身份，只向 Finder 交付本机私密副本，不打开仍在变化的运行目录。显式「放弃续跑」先保存消息停止状态，再结束交接记录；保留日志，不撤销既有副作用、不自动重放不确定操作。
- `TaskArtifactsView` 展示文件工具、Python、技能脚本和 Shell 的真实成果记录。同空间、同完整路径的回执合并为一张紧凑卡片，默认选择传入的本次结果中的最新版本，不随其他任务的后续修改自动前进；不同目录的同名文件分别展示。卡片常驻预览、导出和继续修改，打开副本与 Finder 定位收进操作菜单；版本入口展开完整路径、时间、历史选择和输入来源，历史元数据按需读取。默认显示少量文件，可继续展开或收起，整组导出按文件各导出当前所选版本（默认本次最新），不重复导出中间版本。Shell 普通文件标明运行期间观察到的变化，可能包含同时发生的其他编辑；标准流和文件工具沿用实际发布回执。选中版本后核对本空间保存内容并生成只读副本，原文件删除或修改后仍能预览和导出保留版本。缺内容、保存失败、单文件过大及单次保留总量超限分别说明，旧记录只可使用当前仍可访问的原文件。
- 聊天回答和任务详情把有编辑回执的文件合在一张「已编辑」卡片中。同一路径占一行，显示工作区相对路径和本轮净增删行数。卡头统计文件数，全部文件的行数都能核对时才显示合计。点击文件定位到该文件的差异，「查看变更」打开整份清单。审阅面板支持统一差异、左右对照、修改块跳转、选择版本、预览和导出。
- 差异来自 `files_edit`、`files_apply_changes` 和 `files_write` 保存的前后内容。同一运行、同一实际路径从首次编辑前比较到所选版本。两次编辑之间出现外部修改时，详情仅展示当前步骤并说明原因。旧版本、未保留内容、二进制与超限比较会标明可用范围。打开差异时持有使用凭证，关闭后释放。「撤销」逐次确认，按原工作区和本轮文件版本复核，详见[编程工作流](15-编程工作流.md)。
- 预览、打开只读副本、导出选中版本、整轮导出和继续修改复用同一解析路径。继续修改先补载来源会话，空闲且没有未发草稿时可沿原会话继续；已有草稿、附件或待处理交互时，在已登记工作区新建独立草稿。待发附件在本次运行中按会话保留，未选中草稿仍保护其成果副本，删除会话释放其草稿与使用凭证。继续修改只预填需求并附上带版本号的选中副本，不自动发送，也不授予模型访问应用私有版本目录的权限；发送时沿用现有附件导入和执行审批。后续成果可展开本次任务附加的早期版本并预览仍保留的输入；这表示输入来源，不代替模型实际采用的证据。Finder 定位和旧记录读取仍限定到该消息或运行关联工作区的主目录及显式引用，不能使用同空间其他登记目录。页面消失或切换空间后，迟到的解析结果不能打开预览或触发旧空间的继续操作；已明确选择的导出可完成固定来源的文件写入。
- 任务中心的「成果库」独立分页展示当前空间的版本，提供路径搜索、保留内容/仅来源筛选、历史内容与预览缓存统计，也能找到对话保存失败前已留存的成果。选择后复用同一成果卡；卡片内选择早期版本时同步该版本的来源与继续修改目标，不要求早期记录已加载到当前页。来源会话仍存在时可打开，继续修改先补载并检查其草稿与待处理状态；需要新会话时只使用已登记的关联工作区或空间默认工作区，不扩充目录授权。
- 预览关闭时显式释放其使用凭证，不依赖 SwiftUI 何时丢弃旧视图值；Quick Look 在分配区域内布局，关闭按钮有独立位置与取消快捷键。导出通过异步系统选择器取得用户确认，完成后显示文件数量、位置和访达入口；取消、失败或页面退出不返回成功回执，迟到的选择不会再发布文件。
- 「移除历史副本」逐次确认，只移除选中版本的已保留内容并保留来源记录；「清理预览缓存」另行说明可再生范围。占用中的预览、导出与待发/排队附件阻止清理，结束使用后可重试；副本移除后已挂载成果卡重新读取真实内容状态。失败保留可操作提示，部分缓存清理失败不能被展示为全部成功。来源查询和异步加载丢弃取消或页面退出后的迟到结果。
- 确认卡先展示实际影响摘要，文件操作沿用既有 dry-run 预览；原始参数可展开完整审阅。摘要和折叠不会改变确认等级、授权范围或执行参数。
- 已接入可信执行摘要的脚本调用使用专用确认卡：展示执行档、读取/写入/产物/临时范围、执行器容器、联网与子进程能力、稳定原因与限制来源，并提供互斥的授权有效期（仅这一次 / 本轮相同执行 / 记住这条精确命令）。只展示 Core 声明可用的选项；硬确认只有「拒绝 / 允许一次」，宿主执行不提供回车默认批准。活跃引擎中未接入专用摘要的工具继续使用通用确认卡。
- 应用重启后只有展示快照、没有原引擎句柄的确认和提问改为三语「运行中断，需核对」卡。原参数、问题和已保存轨迹供查看，不提供批准、答复或持久授权，也不以按钮选择生成新模型请求；轨迹不是副作用回执。「结束等待」在所属空间的同一会话事务中清挂起快照并把原回答标为 `recoveryRequired`，落库失败保留卡片，切会话或空间后的迟到结果不改其他运行。之后如需继续，由用户明确发起新任务。
- 任务中心按当前空间展示已归属的 Daemon 恢复记录、隔离证据和同空间重复记录。已归属与本空间未知证据的查看入口点击后重新核对来源和字节，只向 Finder 打开私密副本；同空间重复凭证只显示人工核对警示。旧根无归属证据在空间页面只形成不带记录身份和路径的中立阻挡提示；「设置 → 数据与备份 → 全应用维护」独立窗口明确告知其可能含任一空间内容，用户主动查看副本后才可确认放弃续跑。人工放弃保留现场记录且不会重放、回滚或证明副作用未发生。旧根记录仍可能存在，不能把新记录按空间分区解释成历史证据已迁净。退出交接的 READY 提示仅证明新 Daemon 进程已进入等待全局锁的路径，任务完成仍以持久状态与空间库结果为准。
- 右侧执行档案提供「轨迹」「参考内容」「工具详情」独立页签，与浏览器并列，窄栏可横向滚动页签。关闭单个页签不清除其他页签的数据；重新点击回答的轨迹/参考入口可恢复。参考内容区分历史保留、省略和截断，记录实际请求的图片、系统提示及用量估算，展示请求时的记忆正文快照。非图片附件仅声明路径引用，是否读取由工具步骤证明。失败或超限的图片明确列出，模型不支持图片时同样保留省略提示。纯文本轮次从回答操作栏的参考图标入口直接打开参考页签，悬停显示「参考」。
- 工具详情分别列出本轮可用工具和实际调用，支持搜索，MCP 显示服务与远端工具名；点击实际调用查看参数、结果与耗时。可用目录快照在最后一请求仅输出文本时保留，避免将本轮工具误显示为零。
- 长历史可以把被省略或截断的原文重新补入输入框；「摘要并新建对话」经明确操作把最近的对话片段交给当前模型生成摘要，原对话保持完整。累计计费用量与最近请求的上下文估算使用不同标签。
- 成功检索轨迹保存候选片段；回答下方只展示最终正文用 `knowledge://条目UUID/片段号` Markdown 链接明确采用且能在该回答轨迹中校验的来源。未找到依据、未使用候选、无效 ID 和代码围栏示例不会自动生成来源列表；部分证据只列实际使用的片段。来源点击在当前空间读取原文并定位，文档修改后位置可能变化。

## 记忆、技能与邮箱操作

- 记忆列表显示每条记忆的启用状态。点击行尾的「启用」或「停用」只修改当前空间的这一条记忆，停用后仍可在原处重新启用。
- 自动记忆提炼记录来源会话和消息，并在对应会话提示本次新增，可跳转查看或撤销。撤销停用仍未被用户修改的新增项，保留去重记录，防止下一次提炼重复记回。记忆编辑保留来源和启用状态，删除后迟到的编辑不会重新创建条目。
- 技能列表和空态提供「描述需求创建技能」，跳到当前空间的新对话并预填需求，不自动发送；ZIP 导入继续保留。
- AI 技能重写与文件润色在启动时固定发起空间、Provider 与技能目录；模型和知识检索的异步阶段结束后再次核对空间和取消状态。覆盖前须先保存版本快照，失败不覆盖。润色运行中可取消，空间切换后旧任务不得写入当前空间。
- 空间切换器显示空间文字和图标。知识检索设置先展示就绪、准备中或需要配置的状态；缺模型时保留下载和选择入口，路径配置放入高级区。
- 邮件附件仅在用户选择时按 MIME 部件下载，提供原生预览和 Finder 定位。正文获取失败提供重试；HTML 正文在明暗外观中都使用有边界的浅色阅读纸张，WebView 默认白底深字，邮件作者的 CSS 可覆盖正文背景与文字色，不做全局反色。撰写期间防抖自动保存本机草稿，关闭未保存内容时提示；本机草稿菜单可重新打开，未知或已投递状态以锁定态供核实，不能由自动保存清掉投递证据。发送失败保留页面级提示，关闭撰写窗口后仍有反馈落点。收件人、抄送和密送在发送前校验。
- 邮件导入显示已选来源到实际目录的映射，可展开调整保留层级、收件箱、已有目录或新路径。修改选择、归档和规则立即使旧确认失效，核对完成前禁用导入；无效规则保留编辑入口，已有目录不默选替代项。新归档仅在确认事务中创建，重复项保留原位置。映射及格式预览与关闭保护的完整契约见 [17-邮箱工作流](17-邮箱工作流.md)。
- 邮件导出可选归档文件夹，目录内含原件、可读正文、独立附件与索引，界面说明 HTML 转为文本及部分失败；根索引保存失败可重新导出到新目录。文件夹右键提供本目录与包含子目录两个明确范围，预览显示真实范围，完整契约见 [17-邮箱工作流](17-邮箱工作流.md)。
- 邮件右键的最近及收藏目标可预选现有移动确认；单封和批量标记、移动共用进度与结果。结果栏提供成功邮件定位和会话内撤销预览，列出恢复内容及跳过数；确认前与执行时重新核对，未知结果及永久删除不提供自动回退。切空间作废在途确认及回调，完整边界见 [17-邮箱工作流](17-邮箱工作流.md)。
- 邮件列表提供排序、摘要行数和紧凑程度设置，按空间持久化；查询词在可见主题、发件人和摘要中高亮。正文顶部的独立查找栏使用 WebKit 原生查找，支持上一处/下一处并说明无正文匹配，保持邮件脚本和远程内容限制。新功能与剩余邮箱增强统一验收。
- 单封与会话阅读的附件准备共用 `MailAttachmentQueue`，队列由所属空间的邮箱模型持有，工具栏提供状态入口。附件可单独或全部入队，支持暂停、取消、重试、打开与定位；切换邮件或折叠卡片取消迟到呈现，切换空间取消未完成工作。队列保留有界会话状态，不保存外部授权、不缓存空间服务、不重启自动下载，详见 [17-邮箱工作流](17-邮箱工作流.md)。
- 自动收件箱同步由主窗口的当前空间任务驱动，邮箱列表提供设置与状态入口；只在用户启用后轮询在线收件箱，不要求停留在邮箱页。提醒授权在用户开启选项时申请，后台不弹授权；通知只显示数量与空间。切空间取消旧监视任务，多窗口按实际数据库连接限制单个监视者，恢复备份后默认关闭。新增路径随剩余邮箱功能统一验收。
- 邮件同步失败时仍刷新本地列表：本轮已成功落库的邮件立即可见，不必因后面的文件夹失败而整批不显示；原始同步错误照常保留提示，不静默吞掉。失败提示由结构化诊断生成，指出**操作阶段**（如读取文件夹状态/打开文件夹/读取邮件列表）、**失败类别**（服务器拒绝、响应无法解析、超时、连接中断、会话状态错误、传输失败）、**服务器状态**（`NO`/`BAD`，缺失则不提）与**脱敏后的服务器说明**，并给出下一步动作；不再以「SessionError 错误 N」作为主要原因。日志只记录阶段、状态与脱敏原因，不写密码、授权码、邮件正文或完整协议流量。

## 邮箱连接配置

SMTP 可选择 SSL/TLS（连接开始即加密，常用端口 465）、STARTTLS（连接后升级，常用端口 587）或显式不加密。端口 465 的 SMTP、端口 993 的 IMAP 必须配合 SSL/TLS；界面在测试或保存之前显示不匹配提示，并提供修正加密方式的操作，不静默降级或覆盖管理员指定的自定义端口。

新账号在用户名尚未单独编辑时随邮箱地址填入完整地址；已有或手动填写的短用户名保留，并提供「使用完整邮箱地址」操作。测试错误区分收信连接/登录、文件夹读取与发信连接阶段，避免 SMTP 故障被理解成密码错误。

## 原生小应用

DSL v4 增加原生滑块棋盘。Core 管理整数格子、路径碰撞、原子移动和有界历史；UI 只负责等比布局、临时拖动、吸附动画、方向键/按钮及辅助功能。华容道模板在预览中完整试玩，安装后复用所属空间、应用与安装身份的草稿持久化。减少动态效果时关闭移动动画，空间切换后过期手势不能继续提交。具体限制与生成契约见 [11-原生小应用](11-原生小应用设计.md)。

DSL v3 的宿主能力需求在安装/更新预览中展示。应用窗口提供宿主数据库资源选择器与连接管理入口，连接选择不写入 DSL 状态，也不进入定义导出；切换空间撤销选择并清空结果。工具返回的结构化表可作为动态列表或横向滚动表格展示，顺序动作等待逐步回执和审批，拒绝或停止后不继续后续步骤。剪贴板实现由 UI 注入 Core 能力桥。

数据库工作台按「本地数据库 / 远程数据库」切换，两套列表、选择、操作和异步任务独立。本地页只处理当前空间的 SQLite 文件与 SQL；远程页只管理当前空间的 MySQL 连接并浏览表与字段，不把远程连接交给 SQLite 编辑器。

本地库新建和导入后自动选中；加载结构后选中首张表，空库给出建表或导入提示。刷新操作重读表列表与预览，执行写 SQL 后同步刷新结构并尽量保留当前表。删除用户库需逐次确认，取消并等待当前工作台查询结束、关闭缓存连接后删除文件及 SQLite 辅助文件。应用自身的空间业务库保留为受保护项，不能从工作台删除；其他空间、符号链接和硬链接不进入删除范围。SQL 和预览异步执行，切换数据库会取消旧请求并丢弃迟到结果，运行中提供取消与超时反馈。

MySQL 配置保存与连通性验证分开：编辑器明确说明保存只登记配置，保存后自动选中该连接并尝试加载表与首张表的字段，界面显示未验证、验证中、结构查询成功或失败。连接修改后按修订身份作废旧结构和状态，切换连接或表立即清理旧字段；空结果说明数据库可能为空或缺少表访问权限。删除连接需显示名称并逐次确认，只移除当前空间的连接配置及 Keychain 凭据，不删除服务器上的数据库、表或记录；失败保留配置，成功重新校验选择。

密码输入只存在于编辑器临时状态和 Keychain，不进入配置。编辑服务器、数据库、用户或 TLS 设置时需重新输入密码；编辑密码或替换密码开关会使旧的测试成功标记失效。错误区分认证、TLS、数据库不可用、权限不足和主机解析失败，使用可操作的三语错误，不直接展示底层驱动原文。

侧栏、应用菜单与状态项的「应用」共用应用库路由。`AppsView` 提供图标网格、模板、DSL 导入、预览安装、版本管理、完整应用数据备份/恢复与保留数据的卸载；AI 创建与修改沿用技能创建的对话入口，在当前空间新建并保存需求草稿，不自动发送。定义由当前对话模型生成，前台工具提供规范、确定性校验和所属空间的待安装草稿保存，不另起隐藏的模型请求。应用库展示可恢复草稿、来源会话、继续预览与显式丢弃；关闭预览或重启不会丢失定义，安装成功后才清理对应草稿。预览提供“安装”和“安装并打开”，更新沿用同一流程，安装失败保留草稿。原生窗口按空间与应用 ID 去重。窗口运行实例固定空间和安装身份，切换空间时遮蔽并隐藏旧窗口、同步作废查询及业务/文件管理器中的审批；隐藏窗口只在用户重新打开时恢复查询。私有记录、文件和知识发布都进入共享调度执行边界，预览使用模拟数据并禁用写入。文件管理器支持导入、导出副本、删除与记录关联；记录的编辑目标和修订号随草稿保存。详细 Schema、存储和能力限制见 [11-原生小应用](11-原生小应用设计.md)。

设置分类中的「笔记与录制」集中承接 Memonta 专用偏好；通用、模型服务、工具与自动化、权限与安全、数据与备份分别复用公共配置入口。中央设置与笔记页的快捷弹窗共用所属空间的 `NotesModel`，切换空间重建页面并关闭旧面板。具体映射及生效规则见 [笔记与 Memonta 迁移](18-笔记与Memonta迁移.md)。

## 模型运行参数

设置页「模型服务 → 模型参数与运行预算」位于服务列表之后、折叠的快速接入之前。选择提供商和模型后即可编辑该模型各工作流共用的配置。「自动设置单次回复上限」采用当前模型已知的输出上限，上限未知时回退到本轮工作流的默认值。实际请求还会计入本次输入、工具定义和任务预算。界面分别展示模型能力及来源、上下文输入预算和单次回复上限，自动路由显示各端点的共同范围。输入预算支持手动设置，界面同时显示扣除回复预留与协议余量后的有效值。手动设置从下次运行生效。自动温度跟随提供商默认，不支持温度或思考的模型禁用相应控件。能力刷新失败时保留缓存和手动选择。

工具步数、子代理步数和历史条数列为应用执行策略，消息历史仍受 Token 预算限制。输入区思考力度与设置页使用同一模型偏好，切换模型后重新加载，旧异步结果不能覆盖当前选择；失败保存给出三语提示。设置与能力更新对下一次运行生效，正在运行的任务和退出移交继续使用已冻结的参数。

## 用量页

总览和模型页提供当前日期范围的费用估算及当前空间的模型单价配置。进入页面自动补齐缺失单价，并检查已获取超过一天的价格；「刷新模型价格」可重新查询，手动价格始终优先。OpenRouter 使用其公开模型价格接口，其他已收录端点使用 Models.dev 的提供商价格目录，均按实际端点与模型 ID 精确匹配，不将官方费率套到同名转发或套餐端点。自动价格显示来源与获取时间，并保存不含凭据的服务端点身份；端点变化后旧自动报价失效，用量、聊天预算和定时估算均校验适用范围。查询不携带密钥或空间用量，也不调用模型生成。

提供商身份与实际模型名共同确定费率；缺价格或不完整上报的模型组不计入金额并明确提示，不填成零。本机和未收录模型保留手动填写，新增手填单价默认 CNY；已保存价格和自动报价沿用原币种，不做汇率换算。空白单价不保存为零，明确填写零价仍有效。普通参考费率与缓存用量分开展示，不推测折扣、分时、阶梯、套餐或历史实际价格；不同币种分别汇总。价格与来源保存在空间数据库，任务预算弹窗可读取所选模型的单价。抓取期间的手动输入保留，取消或页面失效后丢弃迟到结果，查询失败保留既有报价；保存时在同一事务中核对旧快照，其他页面的竞争修改要求刷新核对，不能静默覆盖。

单价列表中的模型均可删除，包括没有公开单价、尚未保存价格的历史模型。删除同时移除已保存单价，并在当前空间按提供商身份与模型 ID 记录移除状态；刷新、日期范围变化或重开页面不会从历史请求中重新补回。单价与移除状态在同一事务中核对并保存，其他页面的迟到查询不能恢复已删除项；其他未保存的输入保留。提供「恢复已删除模型」入口，恢复后重新尝试公开价格查询，手动填写过的旧单价不会自动恢复。删除不修改提供商配置、请求历史或 Token 记录，移除状态随空间偏好备份恢复。

费用卡优先显示按币种分列的预估消费，以及各配置的账户余额。宽度不足时两区上下排列。显示时间相同的余额共用一条查询时间。无法查询余额的配置可展开查看，使用同一官方账单页面的配置共用一个链接。估算范围与单价来源说明可从标题旁的信息按钮查看，缺少单价或用量的提示始终可见。

点击「重计」会重新查询已启用且已适配服务商的账户余额，并将当前空间的消费从新起点重新累计。余额和起点在同一事务中保存，查询或保存失败时保留原记录。竞争重计要求刷新，关闭页面、切换空间或更换提供商后丢弃旧请求。未适配余额接口的服务商保留未知。OpenAI 账单链接使用固定的官方地址。原始用量、Token 统计与模型单价保留，重计前已经发起的请求即使后来完成也不补入新范围，毫秒边界按请求身份排除旧回执。

剩余额度逐提供商保留账户币种和查询时间，不合并可能共用同一账户的模型配置；进入页面或用量更新时按分钟节流更新余额，普通余额更新不移动消费起点。已消费额度只取当前空间、重计之后与所选日期范围的交集，继续遵守用量完整性与单价匹配规则；余额与估算币种不同也不推测汇率。重计起点和余额快照随空间偏好持久化及备份恢复。

用量页沿用设置页的分类列表，分为「总览、模型、缓存、请求、会话」；切换分类保留日期范围与请求筛选。页面绑定进入页面时的空间，通过 `Hub.makeUsageService(for:)` 现取服务，显示加载、刷新时间和失败重试，失败不回填零。全部时间、今天、近七天、本月与自定义日期使用本地日历，以请求发起时间确定统计范围；自定义结束日期包含当天。总览、提供商与模型、每日趋势和会话累计共用日期范围，明细状态筛选只影响请求列表；旧版本只能沿用原消息日期，统计口径说明保留其边界。

顶部突出已报告 Token、模型请求数与失败/取消数，迁移的历史回答另行标记。输入与输出、缓存读写分别跟踪返回该字段的记录数：完全缺失显示「未报告」，部分返回标注「部分已报告」，明确返回的零保留为零；缓存子项不再次加入输入总数。用量缺失、缓存信息不完整与未结束提示可切换到相应明细筛选，这些分类可能重叠，不按互斥比例展示。

模型默认按提供商身份与显示模型名归组，同名模型的响应确认来源与仅有请求模型的来源保留独立明细；不同提供商或实际响应模型不合并。请求表格直接展示秒级时间、模型、状态、已报告 Token 与耗时，展开查看请求/响应模型、缓存分项、来源和所属对话。明细筛选在数据库查询中执行，再按发起时间与 ID 游标分页，不能只筛首批已加载的记录。日期、筛选、刷新及空间切换后的迟到结果均需身份核对；加载更多不能覆盖新的查询。删除对话后仍显示回执，并标记「已删除的对话」。

宽窗口使用自适应摘要卡和表格；窄窗口或较大界面字号下，筛选区换行，表格允许横向滚动。长统计口径收进说明浮层。总览直接展示输入/输出堆叠趋势与模型用量对比，模型页保留来源明细，缓存页展示读取/写入用量和上报覆盖，不将缺失值当成零或推测命中率。趋势覆盖完整所选范围，空日补零；长范围按日历合并为有界数量的时段，点选可查看数值。会话按 Token 排序并展示范围内占比。所有标题、列表与辅助信息使用共享字体角色并响应界面文字偏好。

## 编辑草稿与识别生命周期

Markdown 编辑器固定绑定进入时的空间，编辑即登记草稿并防抖原子落盘；两个空间使用独立恢复文件。切页、切空间与退出前保留草稿，恢复后重新选择保存目标，不沿用过期的外部授权。新建或打开其他文件前提供保存、放弃和取消；读写离开主线程，并拒绝超大文件和非常规文件。退出落盘失败时明确询问保留应用还是放弃本次草稿。

表格按行分页，列数决定每页能容纳多少行。每页重复表头，只给本页单元格创建富文本视图、测量宽度和加载资源。翻回已读页可复用文档内的资源。整表预览最多 32 列、500 个数据行，含表头最多 2,000 格。资源数量、像素和矢量字节预算覆盖整份文档，翻页沿用同一预算。原 Markdown、纯文本导出和笔记打印保留完整表格。

OCR 保存先捕获所属空间及知识服务，服务不可用不能报告成功。页面离开时取消识别、结构化保存和屏幕框选；Vision 请求收到实际取消，并有时间、字节、像素与缩略尺寸限制。语音转写的单次完成闸门覆盖先取消后注册、回调与超时交错；音频页离开会停止录音、转写、播放计时器并清理临时录音。
图片浏览器的 OCR「保存知识」同样在点击时固定空间与知识服务，写前核对当前空间、面板与取消状态；写入已开始后切空间，结果仍只可能留在原空间，不更新新空间界面。
记忆新增在保存成功后才清空输入；保存失败保留草稿，切空间后的迟到分类不继续写入。记忆、OCR 与音频页面的常见失败按领域映射三语原因和下一步操作；图片浏览器的 OCR 识别与知识保存也走同一错误呈现，不显示系统原始错误或源文件路径。

邮箱签名和常用回复模板使用空间内 `mail.compose.presets` 偏好；整份快照比较防止并发覆盖，默认签名按账号关联，备份校验纯文本内容及引用。撰写窗口固定空间，仅对未保存且正文为空的新草稿应用默认签名；手动插入先预览，替换需明确选择，编辑变化后作废旧预览与撤销。详细行为与适用范围见 [邮箱工作流](17-邮箱工作流.md)。

服务器草稿的显式预览保存、远端读取替换、未决上传及旧版清理通过空间内 `mail_server_drafts` 凭证与账号租约接入；本机自动保存不联网。上传前固定内容和 Message-ID，未知结果只读核对、不自动重放；投递后清理须有独立本机投递凭证，不允许重发。完整备份校验快照、保留目标库已有凭证，恢复后的关联须重新核对。详细契约与行为边界见 [邮箱工作流](17-邮箱工作流.md)。

## 笔记

常用分组新增「笔记」，通过当前空间的 `NotesModel` 和 `Hub.makeNoteStore(for:)` 组装；独立「笔记」菜单与页面使用同一组动作。能力映射、数据边界与交互验收见 [笔记与 Memonta 迁移](18-笔记与Memonta迁移.md)。

离开页面或关闭主窗口时，`NotesLifecycle` 保留仍在处理、录制或含未保存草稿的模型；重开主窗口复用同一空间与 Hub 的活动模型。换空间显式停止并归档采集、取消处理及关闭播放/朗读/贴图/OCR 资源。退出先完成保存和取消收尾，仅交接预览中已获允许的队列任务；菜单栏录音状态只持有空间和所有者身份，不持有笔记内容。
